## 排障补充：git reset 在 sandbox 下
- `git merge --abort` / `git reset --hard` 在普通 sandbox 下会被拦截（exit 1 / index.lock 冲突）。必须 `dangerouslyDisableSandbox:true` 跑 git 写操作才能落盘。
- 另一个 git 进程（GitHubDesktop.exe GUI）未持 git.exe 子进程时，`.git/index.lock` 是 stale 锁，可直接 `rm -f` 后 reset。
