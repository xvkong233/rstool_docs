# rsWallJoin · Join Walls

> Module: Architecture / 3D Walls

[← Back to command index](/en/commands/)

**Function**: Extend and intersect two smart walls

**Run**: Enter `rsWallJoin` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select the first wall (and specify the reserved side)
2. Select the second wall
3. Two wall extensions intersect and merge

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
