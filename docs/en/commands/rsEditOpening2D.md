# rsEditOpening2D · Edit 2D Opening

> Module: 2D Architecture / Doors, Windows & Elevators

[← Back to command index](/en/commands/)

**Function**: Modify the parameters of the selected door, window/elevator (size, opening direction, elevator size, etc.) and regenerate symbols and wall openings

**Run**: Enter `rsEditOpening2D` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsEditOpening2D
2. Select the door/window/elevator to edit
3. Modify parameters in the option line (door width/window width/opening angle/turning direction/elevator width and depth, etc., change with type)
4. Press Enter to confirm, preview updates in real time and reopen the wall hole

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Parameter items change dynamically with the opening type, and the default value is the existing parameter of the opening (non-fixed numerical input)
