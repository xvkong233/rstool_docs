# rsFlipClosedMeshOutward · Flip Closed Mesh Outward

> Module: Geometry / Meshes

[← Back to command index](/en/commands/)

**Function**: Closed mesh with normals facing outward (modify in place)

**Run**: Enter `rsFlipClosedMeshOutward` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select one or more closed meshes
2. Flip so that its normals face outwards

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Only takes effect on closed meshes
