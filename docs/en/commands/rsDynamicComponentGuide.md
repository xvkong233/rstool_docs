# rsDynamicComponentGuide · Getting started with dynamic components

> Module: Dynamic Components / Getting Started

[← Back to command index](/en/commands/)

**Function**: The Getting Started Guide window pops up, browse the key points of creation and editing by tab page; click "Close" to exit.

**Run**: Enter `rsDynamicComponentGuide` in the Rhino command line (command-line interaction).

**Workflow**:

1. Run rsDynamicComponentGuide, and the "Getting Started with Dynamic Components" window will pop up (top, zoomable, centered on the Rhino screen).

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: A must read if you are using dynamic components for the first time. The quick start page gives selection suggestions and a five-step creation process for "ordinary geometric integration vs. dynamic component assembly"; the basic formula page lists available functions such as $parameter name / node name.Size.
