# rsSelectSubDEdgeDirection · Select Co-Directional SubD Edges

> Module: SubD Tools / Editing Tools

[← Back to command index](/en/commands/)

**Function**: Select all edges with the same direction in the SubD quadrilateral area

**Run**: Enter `rsSelectSubDEdgeDirection` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select SubD object
2. Click on a control network edge
3. Automatically select all edges in the same direction (U or V)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Only takes effect for SubD regions of quad topology.
