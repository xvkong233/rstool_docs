# rsConvertA2DToNormalCurves · Convert 2D Architecture to Curves

> Module: 2D Architecture / Other 2D Tools

[← Back to command index](/en/commands/)

**Function**: Convert selected A2D wall/door/window objects to normal Rhino curves (clear RsTool metadata, delete wall hatch)

**Run**: Enter `rsConvertA2DToNormalCurves` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsConvertA2DToNormalCurves
2. Select the 2D walls/doors and windows to be converted (curve/fill, you can select multiple boxes)
3. Automatically convert it to a normal Rhino curve and remove A2D metadata (removes wall fill)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: No parameters; A2D smart associations are lost after conversion
