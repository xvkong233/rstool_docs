# rsDynamicComponent · Dynamic Components Panel

> Module: Dynamic Components / Panels

[← Back to command index](/en/commands/)

**Function**: Opens the Dynamic Components panel: displays component options for the currently selected instance, or displays the template's component editor in editor mode.

**Run**: Enter `rsDynamicComponent` in the Rhino command line (command-line interaction).

**Workflow**:

1. Enter rsDynamicComponent at the command line to open the Dynamic Components panel (docked to the side of Rhino).

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: There are two parts of the panel - "Component Options" to change the public parameters of the current instance (multi-select batches and template values can be restored); "Component Editor" to change the template structure/default value/node formula/subcomponent binding/action. You must click "Save Template" to take global effect (you can see the preview and error list before saving). Editor changes are only drafts and will not affect the instance if they are not saved.
