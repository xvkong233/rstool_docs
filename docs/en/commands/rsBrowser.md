# rsBrowser · Break-Time Browser

> Module: Fun / Interactive Entertainment

[← Back to command index](/en/commands/)

**Function**: Toggle display/hide of the built-in browser panel (RhinoBrowserPanel)

> Screenshots and videos may show a Chinese-language interface. Labels and control positions can vary by Rhino or RSTool version.

**Run**: Enter `rsBrowser` in the Rhino command line (command-line interaction).

**Workflow**:

1. Enter rsBrowser on the command line to switch the display/hide of the built-in browser panel
2. Close if the panel is open, otherwise open

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Toggle command: Repeatedly run to switch between show/hide
