# rsExplodeNestedBlocks · Explode nested blocks

> Module: Utilities / Block Operations

[← Back to command index](/en/commands/)

**Function**: Recursively explode all nested block references back to the lowest level geometry/non-nested reference

**Run**: Enter `rsExplodeNestedBlocks` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsExplodeNestedBlocks
2. Find all instances of blocks in a document
3. Recursively explode nested tiles layer by layer
4. Redraw view

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
