# rsScreenPin · Screenshot floating window

> Module: Productivity / Screen Tools

[← Back to command index](/en/commands/)

**Function**: Capture the screen and generate a draggable/zoomable floating image on top

**Run**: Enter `rsScreenPin` in the Rhino command line (opens a settings window).

**Workflow**:

1. Command line input rsScreenPin
2. Show ScreenPinControlForm control panel
3. Click "Screenshot" to capture the screen area and float it on top
4. You can use the scroll wheel to zoom, drag, and right-click for more operations; "Close all" to clear

**Parameters**:

| Display name | Parameter | Type | Default | Range | Description |
| --- | --- | --- | --- | --- | --- |
| interaction | Interaction | text | — | Take a screenshot / close all floating pictures | The control panel is button-operated and has no numerical parameters; the floating window supports dragging, wheel zooming, and right-clicking for more operations. |

**Notes**: Eto control panel + screen area selector; no numerical parameters (zoom to interactive)
