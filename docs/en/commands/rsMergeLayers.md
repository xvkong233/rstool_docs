# rsMergeLayers · Merge layers

> Module: Organization & Selection / Layers

[← Back to command index](/en/commands/)

**Function**: Merge selected source layers to the target layer and delete the source layers (including objects inside the block)

> Screenshots and videos may show a Chinese-language interface. Labels and control positions can vary by Rhino or RSTool version.

**Run**: Enter `rsMergeLayers` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsMergeLayers
2. In the pop-up multi-layer selection dialog box, select the source layers to be merged.
3. Select target layer
4. The program moves the source layer objects into the target layer and deletes the source layer

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: If the source layer collection contains the target layer, remove the target layer from the source list first
