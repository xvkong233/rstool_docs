# rsDualMesh · Dual Mesh

> Module: Geometry / Meshes

[← Back to command index](/en/commands/)

**Function**: Convert each face of the mesh into a dual mesh of one vertex

> Screenshots and videos may show a Chinese-language interface. Labels and control positions can vary by Rhino or RSTool version.

**Run**: Enter `rsDualMesh` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select mesh
2. Generate dual mesh (face center → vertex)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: No tunable parameters
