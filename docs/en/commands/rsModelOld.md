# rsModelOld · Old model library

> Module: Libraries / Model Library

[← Back to command index](/en/commands/)

**Function**: Open the old model library window, browse and insert models/components

**Run**: Enter `rsModelOld` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsModelOld
2. Create and display the rsModelDialogOld (WinForms) window
3. Select the model in the legacy library browser and insert

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Legacy command, WinForms implementation; as fallback to rsModel
