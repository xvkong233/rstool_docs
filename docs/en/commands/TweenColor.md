# TweenColor

> Module: Grasshopper Components / Color

[← Back to command index](/en/commands/)

![Icon](../../assets/gh-icons/TweenColor_24.png)

**Function**: Linearly interpolates between two colors.

**Usage**:

1. In the Grasshopper canvas, find the component under the "Color" group of the RsTool tab and drag it in
2. Connect each input port according to the parameter table (the ports marked "optional" are empty ports)
3. Executed once each time the canvas is solved, reading the results from the output port

**Parameters**:

> This component has no input parameters and runs automatically whenever the Grasshopper solution is evaluated.

**Notes**: This component runs in the Grasshopper canvas, with inputs and outputs connected through component ports; it is executed once each time the canvas is solved.

Belongs to GH group: RsTool / Color
