# rsCopyOpening2D · Copy 2D Opening

> Module: 2D Architecture / Doors, Windows & Elevators

[← Back to command index](/en/commands/)

**Function**: Copy selected doors/windows/elevators to multiple target locations (retaining original parameters)

**Run**: Enter `rsCopyOpening2D` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsCopyOpening2D
2. Select the door/window/elevator to copy
3. Automatic selection of candidate host walls
4. Click Copy at the target location (Enter/Esc to end)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: No numerical parameters; can be copied multiple times in succession
