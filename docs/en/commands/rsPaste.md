# rsPaste · Paste with origin

> Module: Utilities / Clipboard

[← Back to command index](/en/commands/)

**Function**: Paste objects from the clipboard into the document based on reference points and automatically rebuild block definitions, layers and materials

**Run**: Enter `rsPaste` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsPaste
2. Read rsCopy clipboard data
3. Specify paste placement point (dynamic preview)
4. Place objects offset by reference point (automatically handles units, blocks, layers)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
