# rsWall2DReconnect · 2D wall reconnection

> Module: 2D Architecture / Grids & Walls

[← Back to command index](/en/commands/)

**Function**: Repair connecting joints between selected 2D walls

**Run**: Enter `rsWall2DReconnect` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsWall2DReconnect
2. Select the two-dimensional wall that needs to be repaired (curve/fill, multiple selections can be made)
3. Automatically repair joints of selected walls

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: No parameters, pure selection operation
