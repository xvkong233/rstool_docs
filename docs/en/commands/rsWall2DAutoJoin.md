# rsWall2DAutoJoin · Auto-Join 2D Walls

> Module: 2D Architecture / Grids & Walls

[← Back to command index](/en/commands/)

**Function**: Automatically break and join selected 2D walls at intersections/endpoints to generate continuous wall segments (including smart joints at doors and windows)

**Run**: Enter `rsWall2DAutoJoin` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsWall2DAutoJoin
2. Select at least two 2D walls (curve/fill, multiple selections available)
3. Automatically break and rejoin walls at intersections/endpoints (including door and window aware joints)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: At least two walls need to be selected; no numerical parameters
