# rsHelp · Open Help

> Module: Utilities / System Tools

[← Back to command index](/en/commands/)

**Function**: Open the RSTool online documentation in your default browser.

**Run**: Enter `rsHelp` in the Rhino command line (command-line interaction).

**Workflow**:

1. Run rsHelp to open https://docs.rstoolarchi.com/ in your default browser.
2. Use the index or search to find a command.

**Parameters**:

> No numeric settings or separate settings window are required. Follow the workflow above.

**Notes**: No selection, numeric input, or settings dialog is required. An internet connection to the documentation site is needed.
