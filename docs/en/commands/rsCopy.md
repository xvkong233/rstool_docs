# rsCopy · Copy with origin

> Module: Utilities / Clipboard

[← Back to command index](/en/commands/)

**Function**: Write the selected object (including layer, material, nested block definition) and reference point to the RsTool local temporary clipboard for use by rsPaste

**Run**: Enter `rsCopy` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsCopy
2. Select the object to be copied (supports pre-selection and group selection)
3. Specify copy reference point
4. Objects and reference points are written to the RsTool temporary clipboard (.3dm file)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
