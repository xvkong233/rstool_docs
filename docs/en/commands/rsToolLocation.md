# rsToolLocation · Open the plugin directory

> Module: Utilities / System Tools

[← Back to command index](/en/commands/)

**Function**: Open the RsTool plug-in installation directory in the system file manager

**Run**: Enter `rsToolLocation` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input RsToolLocation
2. Get the plug-in installation directory path
3. Open the directory in Explorer

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
