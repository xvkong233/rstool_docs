# rsEarthOld · Legacy Terrain Downloader

> Module: Terrain / Acquisition & Editing

[← Back to command index](/en/commands/)

**Function**: Write the terrain mesh and its texture obtained by box selection into the current document

**Run**: Enter `rsEarthOld` in the Rhino command line (command-line interaction).

**Workflow**:

1. The old version of the map form (MapDialog, WindowsForms, non-modal) pops up after the command is started.
2. Select the area in the map form and confirm the download
3. Form writes terrain mesh to current document

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: The old terrain download command has been replaced by rsEarth; it is a legacy implementation.
