# rsConvertToMeshPanel · NURBS unit to Mesh unit

> Module: Geometry / Meshes

[← Back to command index](/en/commands/)

**Function**: Mesh panels converted from curved surfaces

**Run**: Enter `rsConvertToMeshPanel` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select one or more surfaces / Brep
2. Convert each Brep face to a triangle/quad/polygon mesh panel

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Filter is Surface\|Brep; no parameters
