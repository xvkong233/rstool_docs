# rsMayaTransferSettings · Rhino-Maya transfer settings

> Module: Utilities / Import & Export

[← Back to command index](/en/commands/)

**Function**: Open the Rhino-Maya Transfer Settings window

**Run**: Enter `rsMayaTransferSettings` in the Rhino command line (opens a settings window).

**Workflow**:

1. Command line input rsMayaTransferSettings
2. The Rhino-Maya transfer settings window pops up
3. Close the window after configuring transmission parameters

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Running it again when the window is already open will pin it to the top and will not create it again.
