# rsCloseObjLayer · Close the layer where the object is located

> Module: Organization & Selection / Layers

[← Back to command index](/en/commands/)

**Function**: Hide (turn off) all layers containing selected objects

**Run**: Enter `rsCloseObjLayer` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsCloseObjLayer
2. Select the object whose layer you want to turn off
3. The program closes the layer where these objects are located (skipping locked layers)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Skip locked layers; locked layers will not be processed
