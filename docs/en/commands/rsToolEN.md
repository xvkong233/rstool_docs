> Module: Utilities / System Tools

[← Back to command index](/en/commands/)

**Function**: Show the RSTool 2.0 English toolbars and remember the language preference locally.

**Run**: Enter `rsToolEN` in the Rhino command line (command-line interaction).

**Workflow**:

1. Run `rsToolEN`.
2. Use the displayed English toolbars. A later `rsToolStart` uses this saved language preference.

**Parameters**:

> No numeric settings or separate settings window are required. Follow the workflow above.

**Notes**: This changes the toolbar language. Rhino interface language is controlled separately. Use `rsToolCN` for Chinese toolbars.
