# rsAssignRandomColorToLayer · Assign Random Layer Colors

> Module: Organization & Selection / Layers

[← Back to command index](/en/commands/)

**Function**: Randomly assign colors to all layers that are still the default black (0,0,0), retaining layers with already set colors

**Run**: Enter `rsAssignRandomColorToLayer` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsAssignRandomColorToLayer
2. The program traverses the default black (0,0,0) layer and assigns colors randomly

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Only modify the layer color of R=G=B=0; no interactive parameters, it is a batch command
