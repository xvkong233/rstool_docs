# rsDeleteLayer · Delete layer

> Module: Organization & Selection / Layers

[← Back to command index](/en/commands/)

**Function**: Delete selected layers

**Run**: Enter `rsDeleteLayer` in the Rhino command line (opens a settings window).

**Workflow**:

1. Command line input rsDeleteLayer
2. In the pop-up layer selection dialog box, select the layer you want to delete.
3. Confirm deletion

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: The layer hierarchy relationship will be processed before deletion. Please pay attention to whether the sublayers are deleted together.
