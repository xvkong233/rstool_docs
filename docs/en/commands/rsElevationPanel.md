# rsElevationPanel · Elevation panel

> Module: 2D Architecture / Other 2D Tools

[← Back to command index](/en/commands/)

**Function**: Generate elevation panels from elevation objects

![Elevation panel: Title elevation/prompt Double-click the elevation to display the corresponding floor range/table column name and elevation (2F +6.000m, 1F ±0.000)/button to pick elevation/add/delete/floor display range lower range (m) and upper range (m) default 1.400/button to update section/show all](../../assets/rsElevationPanel/image1.png)
*Figure 1: Elevation panel. The window title is "Elevation", and the gear in the upper right corner is the setting button; the top prompts "Double-click the elevation to display the corresponding floor range"; the middle is the elevation list table (two columns: name/elevation), 2F (+6.000 m) is currently selected, and 1F (±0.000) is below; the first row of the button area "Pick elevation / Add / "Delete" is used to pick up section elevations from the model or add/delete elevation entries; the "Floor Display Range" in the middle can be set to "Lower Range (m)" and "Upper Range (m)" (the default is 1.400), which determines the vertical display height of the floor in the Rhino viewport when the elevation is clicked; "Update Section" at the bottom refreshes the Rhino section view according to the current elevation, and "Show All" displays the floor range corresponding to all elevations with one click*

> Screenshots and videos may show a Chinese-language interface. Labels and control positions can vary by Rhino or RSTool version.

**Run**: Enter `rsElevationPanel` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select the elevation object or group generated by rsElevation2D (multiple selections possible)
2. Generate elevation panel

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: The input object needs to be the elevation object or group generated by rsElevation2D.
