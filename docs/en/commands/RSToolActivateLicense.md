# RSToolActivateLicense · Activate license

> Module: Utilities / System Tools

[← Back to command index](/en/commands/)

**Function**: Open the RsTool license activation dialog box (enter the activation code to complete activation)

**Run**: Enter `RSToolActivateLicense` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input RsToolActivateLicense
2. Check if activated/verifying
3. Open the license activation window when not activated (enter activation code)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
