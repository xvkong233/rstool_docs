> Module: Utilities / System Tools

[← Back to command index](/en/commands/)

::: warning Version 2.0: legacy entry

Sign in and authorize the device in the RSTool client. Version 2.0 no longer uses the old standalone activation command.

The old name is not a callable alias in the reviewed 2.0 source. The historical reference below is for 1.x.

[View the 2.0 command changes](/en/commands/v2)

:::

::: details View the 1.x historical reference

> Icons, screenshots, parameters, and workflows in this section describe the old version.

**Function**: Open the RsTool license activation dialog box (enter the activation code to complete activation)

**Workflow**:

1. Command line input RsToolActivateLicense
2. Check if activated/verifying
3. Open the license activation window when not activated (enter activation code)

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.


:::
