# rsWallRemoveHole · Remove holes in wall

> Module: Architecture / 3D Walls

[← Back to command index](/en/commands/)

**Function**: Remove opening cutter from wall

**Run**: Enter `rsWallRemoveHole` in the Rhino command line (command-line interaction).

**Workflow**:

1. Choose a smart wall
2. Select the red cutout (hole) cutter to remove
3. Press Enter to remove all/remove one by one
4. Wall openings removed

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Enter = remove all holes
