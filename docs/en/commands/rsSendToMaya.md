# rsSendToMaya · Send model to Maya

> Module: Utilities / Import & Export

[← Back to command index](/en/commands/)

**Function**: Send selected objects to Maya

**Run**: Enter `rsSendToMaya` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select objects to send to Maya
2. Transfer to Maya

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: Transmission parameters (such as units, axial direction) are configured in rsMayaTransferSettings.
