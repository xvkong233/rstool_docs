# rsWallExtend · Extend Wall

> Module: Architecture / 3D Walls

[← Back to command index](/en/commands/)

**Function**: Extend selected walls to bounding walls

**Run**: Enter `rsWallExtend` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select boundary wall
2. Cycle through the walls you want to extend
3. Selected walls extend to boundary walls

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
