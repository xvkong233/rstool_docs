# rsUnifyQuadMesh · Unified quadrilateral mesh

> Module: Geometry / Meshes

[← Back to command index](/en/commands/)

**Function**: Four-sided mesh with unified vertex arrangement direction (row/column)

**Run**: Enter `rsUnifyQuadMesh` in the Rhino command line (command-line interaction).

**Workflow**:

1. Select the four-sided mesh
2. Unify UV/vertex directions by BFS row and column

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: No tunable parameters
