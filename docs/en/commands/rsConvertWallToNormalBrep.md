# rsConvertWallToNormalBrep · Convert wall to normal Brep

> Module: Architecture / 3D Walls

[← Back to command index](/en/commands/)

**Function**: Convert smart wall to normal Brep and clear smart wall metadata

**Run**: Enter `rsConvertWallToNormalBrep` in the Rhino command line (command-line interaction).

**Workflow**:

1. Choose Smart Wall Brep
2. Convert to normal Brep and clear smart wall metadata

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.
