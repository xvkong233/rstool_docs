# rsProfileDirectorAddProfile · Add Profile

> Module: Section Management / Profile Director

[← Back to command index](/en/commands/)

**Function**: Save selected closed planar curves as sections to the ProfileDirector user section library

**Run**: Enter `rsProfileDirectorAddProfile` in the Rhino command line (command-line interaction).

**Workflow**:

1. Command line input rsProfileDirectorAddProfile
2. Select a closed planar profile curve
3. Specify section reference point
4. Enter section name
5. Save to ProfileDirector profile library

**Parameters**:

> This command has no numeric command-line parameters. Adjust its options in the settings window.

**Notes**: No numerical parameters; only closed and planar curves accepted; reference points are used for positioning
