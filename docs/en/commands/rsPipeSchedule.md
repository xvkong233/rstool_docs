# rsPipeSchedule · Pipe Schedule

> Module: Architecture / Building Elements

[← Back to command index](/en/commands/)

**Function**: Read smart-pipe metadata and export a CSV grouped by type, specification, and generation-time units.

**Run**: Enter `rsPipeSchedule` in the Rhino command line (command-line interaction).

**Workflow**:

1. Run, select runs and fittings generated by rsSmartPipe, and press Enter.
2. Choose the CSV destination to export the recorded quantities.
3. Open it in a spreadsheet and review type, diameter × thickness, quantity, net pipe length, fitting centerline length, and generation-time units.

**Parameters**:

> No numeric settings or separate settings window are required. Follow the workflow above.

**Notes**: Only objects with supported smart-pipe data (RSTool.Pipe.Version=1) are counted; ordinary Pipe objects and manually modeled fittings are not inferred. CSV uses UTF-8 BOM for spreadsheet compatibility. Values come from generation-time records, not remeasurement of edited geometry. Regenerate pipes after scaling or reshaping before scheduling. No settings dialog is used.
