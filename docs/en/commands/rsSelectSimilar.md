# rsSelectSimilar · Similar object selection

> Module: Organization & Selection / Selection

[← Back to command index](/en/commands/)

**Function**: Select all objects that meet the checked rules with the reference object (traverse according to "matching range", calculated according to each rule + allowed difference)

![rsSelectSimilar Similar object selection dialog box](../../assets/rsSelectSimilar/image1.png)
*Similar object selection dialog: sample objects, match ranges, dynamic rule groups, and numerical tolerances*

> Screenshots and videos may show a Chinese-language interface. Labels and control positions can vary by Rhino or RSTool version.

**Run**: Enter `rsSelectSimilar` in the Rhino command line (opens a settings window).

**Workflow**:

1. Command line input rsSelectSimilar
2. Select a reference object (curve/surface/mesh/block/text/fill, any RhinoObject)
3. Select the matching range: the entire document or the frame selection candidate range (click "Frame selection candidates..." to enter the Rhino native window selection, left → right window selection, right → left cross selection)
4. The dialog box displays the number of candidates currently meeting the check rules in real time; you can click "Recommend Rules/Check All/Clear All" to quickly adjust the check.
5. Set "allowed differences" for numerical rules (tolerances for line width/length/area/volume/bounding box/direction angle/integer count)
6. Check "Keep and add to current selection" to merge with the existing selection; otherwise, replace the current selection
7. Click "Select matching objects" to perform the selection (click "Cancel" to make no selection)

**Parameters**:

| Display name | Parameter | Type | Default | Range | Description |
| --- | --- | --- | --- | --- | --- |
| Match range | candidateScope | enum | entire document | Entire document/frame selection candidate range | Dropdown controls the candidate object pool: the entire document = traverses all objects in doc.Objects; frame selection candidate range = first use the Rhino native window to select and obtain the candidate ID set (click "Frame selection candidate object..." to trigger; the status bar prompts "Not yet frame selected"/"N number selected") |
| Filter rules (check) | criteria | toggle | By sample type, the object type/geometry subtype/layer/area/volume/closed/closed entity/number of points/block definition/fill pattern, etc. are checked by default. |  | Dynamic generation: Display different rule groups (general attributes/geometric measures/topology and form/bounding box and position/content and definition) according to the reference object type. Each rule has a check box; check it as a filter condition |
| allow differences | difference | double | Line width 0.001mm, direction 1.0°, point/curve starting point and end point = model tolerance, length/area/volume/bounding box size = max (model tolerance, sample value × 1%), integer count 0 | 0 ~ 1e18 | Only numerical rules can be set; NumericStepper MinValue=0 MaxValue=1e18, Increment/DecimalPlaces change with the rules (line width Increment=0.01 / direction Increment=0.5 / integer Increment=1 / other Increment=max (model tolerance, 0.001)) |
| Keep and add to current selection | AddToSelection | toggle | false |  | After checking, retain the original selection and append matching objects (Rhino SelectObjects with enable=true + previousSelected=true behavior); if not checked, replace the current selection |

**Notes**: **Rule grouping (dynamically generated by `SimilarSelectionRuleFactory.Create`)**:

- **Common properties (10 items, Common)**: Object type, geometry subtype GeometrySubtype (such as Line / Polyline / Arc / Circle / NURBS curve / Single-face Brep / Multi-face Brep / Mesh / Point / Point cloud / Block instance / Hatch / Text, etc.), layer Layer (FullPath path), object name Name, display color DisplayColor (DrawColor, *includes accompanying layer*), printing color PlotColor, effective linetype Effective Linetype, effective material Effective Material, effective printing line width Effective PlotWeight (numeric value, default 0.001mm tolerance / Increment=0.01 / 3 decimal places), the number of groups it belongs to GroupCount (integer). The first 3 items are checked by default, and the rest are checked as needed.

- **Geometry, dynamically appears according to geometry type**: Curve length CurveLength (numeric value, default tolerance = max (model tolerance, sample value × 1%), unit = model length unit), curve starting point CurveStart (point, tolerance = model tolerance), curve end point CurveEnd (point), head and tail direction CurveDirection (vector, only appears when the sample is not empty; use `VectorAngle` to calculate the angle and 180 - Take the smaller value of the included angle, tolerance = angle °, default 1°, Increment=0.5, 2 decimal places, **Ignore reverse**), Area (numeric value, unit = length unit²), Volume (numeric value, only available for entities, unit = length unit³). Curve length/area/volume/start point/end point/direction are checked by default.

- **Topology and form (appear dynamically according to geometry type)**: Closed (Boolean), plane curve Planar (curve only), closed solid solid (Brep / Mesh only), curve degree / curve span number SpanCount / control point number ControlPointCount (appear on demand, integer tolerance=0 Increment=1), surface U/V degree Surface U/V Degree, U/V span number Surface U/V SpanCount (only Appears when Brep.Faces.Count==1), number of surfaces FaceCount / number of edges EdgeCount / number of vertices VertexCount / number of bare edge loops NakedEdgeCount (Brep counts as `Edge.Valence==Naked`, Mesh as `GetNakedEdges().Length`), number of mesh faces MeshFaceCount / number of N-gons MeshNgonCount (Mesh only), number of points PointCount (point cloud only, integer tolerance=0). Closed/Closed Entity/Number of Points Checked by default.

- **Bounds & Position (3-4 items)**: World X / Y / Z size BoundingBox X / Y / Z (numeric value, according to the three-axis length of the geometric bounding box, unit = length unit); point coordinate PointPosition (only Point geometry). Bounding box numerical tolerance = max (model tolerance, sample value × 1%).

- **Content & Definition (only specific types)**: block definition InstanceDefinition (only InstanceObject, including Block instance geometry, checked by default), text content TextContent (only Annotation/TextEntity), hatch pattern HatchPattern (only Hatch, checked by default).

**Matching semantics**: Candidate objects are compared with samples one by one. Text classes (name/color/layer/block definition/fill/text) are strictly equal; numerical class `Math.Abs(difference) ≤ max(0, tolerance)`; point class `DistanceTo ≤ max(0, tolerance)`; direction class angle after taking `min(α, \|180-α\|)` ≤ tolerance; Boolean/integer class `Math.Abs(difference) ≤ Tolerance` (integer tolerance=0 means exact equality). **Real-time refresh of match count**: Modifying any check or tolerance will trigger `RefreshMatchCount()` recalculation and display "X / Y matches" at the bottom of the dialog box (X = current number of matches, Y = total number of candidates).

**Shortcut button**: "Recommended Rules" = Press `SelectedByDefault` to reset (different object types have different recommended checks); "Check All" / "Clear All" to switch in full. **Button at the bottom**: "Select matching object" to execute; "Cancel" to abandon the selection; real-time prompt on the right side `Please select the candidate object first` (matching is disabled when no candidate is selected).

**Set persistence**: Check Status/Tolerance/AddToSelection/Candidate Range Mode to be written to disk by `SimilarSelectionSettingsStore` and automatically brought in next time it is opened; all fields can be viewed at `SimilarSelectionSettings.cs`.
