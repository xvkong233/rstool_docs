# RSTool 2.0: command changes

Reviewed against the 2.0 source on 2026-11-11. Use this page to find where an old command has moved; availability depends on the version you have installed.

## What changed

- Walls, doors, windows, curtain walls, and elevators share 2D/3D panels. The double-flight and multi-flight stair panels also include their former 2D commands.
- Select a parametric object and edit it in Properties. Some old editing commands have become Rhino actions or panel controls.
- Libraries, studios, and several utility panels run in the RSTool client. Keep it running and signed in.
- Old command names are not automatically aliases. Update custom toolbar macros and shortcuts to the current entry.

## Replacement commands

| [`rsWallJoin`](/en/commands/rsWallJoin) | [`rsWallConnect`](/en/commands/rsWallConnect), [`rsWallJoint`](/en/commands/rsWallJoint) — Use rsWallConnect to connect or extend wall segments; use rsWallJoint for T and cross junctions. |

| [`rsDoor2D`](/en/commands/rsDoor2D) | [`rsDoor`](/en/commands/rsDoor) — 2D and 3D doors share one window. Choose the output mode in the panel. |

## Rhino actions and panel settings

| Old entry (historical page) | Current entry / action |
| --- | --- |
| [`rsDeleteWall2D`](/en/commands/rsDeleteWall2D) | Select the wall and use Rhino Delete. Connected junctions update with the deletion. |
| [`rsMoveOpening2D`](/en/commands/rsMoveOpening2D) | Select the opening and move it in the wall plane with Rhino Move. Association synchronization handles the position change. |
| [`rsEditOpening2D`](/en/commands/rsEditOpening2D) | Select the door, window, or elevator and edit its building parameters in the Properties panel. |
| [`rsDeleteOpening2D`](/en/commands/rsDeleteOpening2D) | Select the opening and use Rhino Delete. The opening in its host wall updates accordingly. |
| [`RSToolActivateLicense`](/en/commands/RSToolActivateLicense) | Sign in and authorize the device in the RSTool client. Version 2.0 no longer uses the old standalone activation command. |
