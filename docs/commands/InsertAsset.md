# InsertAsset · 插入模型

> 模块：资源库 / 模型库

[← 返回命令目录](/commands/)

**功能**：插入模型库中的模型到当前文档

**调用**：在 Rhino 命令行输入 `InsertAsset`（命令行交互）

**交互流程**：

1. 从模型库面板选择要插入的模型
2. 在视口中拖动定位模型位置
3. 用命令行选项「旋转 90°」或直接输入「角度」调整朝向
4. 点击确认放置

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 旋转 90° | Rotate90 | toggle |  | 每次 +90° | 放置过程中的命令行选项，可多次切换 |
| 角度 | Angle | double | 0.0 | 任意角度（度） | 放置过程中的命令行选项，直接输入朝向角度 |

**备注**：旧版对应命令为 InsertAssetOld。
