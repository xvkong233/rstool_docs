::: details 查看 1.x 历史说明

> 本节的图标、截图、参数与操作流程均为旧版资料。

**功能**：在指定位置打断二维墙体

**交互流程**：

1. 选择一面要打断的二维墙体
2. 在墙体上指定打断点
3. 墙体被打断成两段

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：需要打断的是 rsWall2D 生成的智能二维墙体。


:::
