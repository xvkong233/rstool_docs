# rsMergeLayers · 合并图层

> 模块：组织与选择 / 图层

[← 返回命令目录](/commands/)

**功能**：将所选多个源图层合并到目标图层，并删除源图层（含图块内部对象）

**调用**：在 Rhino 命令行输入 `rsMergeLayers`（命令行交互）

**交互流程**：

1. 命令行输入 rsMergeLayers
2. 在弹出的多图层选择对话框中选择要合并的源图层
3. 选择目标图层
4. 程序将源图层物体移入目标图层并删除源图层

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：若源图层集合包含目标图层，则先从源列表移除目标图层
