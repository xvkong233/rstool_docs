# rsRandomOffsetSrf · 随机偏移曲面

> 模块：几何 / 曲面

[← 返回命令目录](/commands/)

**功能**：新增偏移后的曲面或实体（Brep），原对象保留；生成结果会成组并选中。

**调用**：在 Rhino 命令行输入 `rsRandomOffsetSrf`（打开设置窗口）

**交互流程**：

1. 在 Rhino 命令行输入 rsRandomOffsetSrf，打开随机偏移曲面窗口
2. 点击“选取物体”，选择一个或多个曲面、或多重曲面，按回车确认
3. 设置最小、最大厚度，选择偏移方向及是否生成实体；根据需要调整“延伸曲面”
4. 查看视口中的半透明预览，满意后点击“生成”

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 最小厚度 | Minimum | 数值 | 0.1 米（按文档单位换算） | > 0，且不大于最大厚度 | 每个源对象的随机厚度下限；同一多重曲面整体使用一个随机厚度。 |
| 最大厚度 | Maximum | 数值 | 1 米（按文档单位换算） | ≥ 最小厚度 | 每个源对象的随机厚度上限；调节范围时预览会更新，随机顺序保持稳定。 |
| 偏移方向 | Direction | 选项 | 法线正面 | 法线正面 / 法线反面 / 两侧（居中） | 前两项向法线一侧偏移；居中时厚度分布在源曲面的两侧。 |
| 生成实体 | Solid | 开关 | 是 | 是 / 否 | 开启时生成有厚度的实体；关闭时只生成偏移曲面，居中方向会生成正反两侧曲面。 |
| 延伸曲面 | Extend | 开关 | 是 | 是 / 否 | 偏移时延伸相邻曲面，帮助处理多重曲面连接处。 |

**备注**：这里的“随机”是每个源对象一个厚度，不是多重曲面的每个面各自随机。若偏移失败，可减小厚度或检查源曲面；窗口会提示失败数量。
