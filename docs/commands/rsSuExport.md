# rsSuExport · 导出SketchUp

> 模块：辅助工具 / 导入导出

[← 返回命令目录](/commands/)

**功能**：生成按 Rhino 图层组织为顶层组件的 SKP 文件；普通物体有独立组件，已有块尽量保留实例关系，曲面几何使用渲染网格导出。

**调用**：在 Rhino 命令行输入 `rsSuExport`（命令行交互）

**交互流程**：

1. 运行 rsSuExport，指定要导出的模型和 .skp 保存位置
2. 命令把普通物体分别整理成 Block；已有 Rhino Block 则保留实例和嵌套关系
3. 再按照 Rhino 图层，把同层物体打包成外层 Block，方便在 SketchUp 中按图层成组选中和管理
4. 导出时优先提取 Rhino 的渲染网格；完成后生成 SKP 文件并报告处理数量

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 输出路径 | OutputPath | file | 用户选择 | *.skp | 通过保存对话框指定；目标格式固定为 SketchUp 2016，命令不提供其他导出选项。 |

**备注**：

## 它到底做了什么

可以把这个命令理解成“先整理模型，再导出 SKP”。普通物体会分别包装成 Block；Rhino 里原本就是 Block 的对象，则尽量保留共享定义和嵌套关系。然后，命令按 Rhino 图层再套一层 Block：同一图层的内容会放在同一个外层组件里。这样模型进了 SketchUp 以后，按图层找东西、成组选中或隐藏都会更顺手。

## 为什么导入 SketchUp 后通常更好用

对曲面、多重曲面、拉伸体等几何，命令会优先取 Rhino 已有的**渲染网格**；没有可用的网格时，再按对象或文档的网格设置生成。SubD 会以中等显示密度生成网格。重复使用的 Rhino Block 会继续共用转换后的定义，不会为了每个实例都重新做一份完整几何。

这些处理有助于控制组件结构和几何复杂度，通常能减轻 SketchUp 里选取、隐藏和浏览模型时的负担。但如果源模型本身面数很高，导入后仍可能卡顿；“自动变流畅”不是这个命令能保证的结果。

## 导出前，先看看 Rhino 里的显示精度

SKP 里看到的曲面效果，主要取决于 Rhino 导出时使用的渲染网格。建议先在 Rhino 的着色或渲染视图里看看弧面、圆柱和曲线边缘：已经明显有棱角，就适当提高网格精度；显示很细但模型特别重，就考虑把网格调得合理一些。**精度越高，面数和文件体积通常也越大**，到 SketchUp 里反而可能更卡。先把 Rhino 的显示效果与网格密度调到合适，再运行命令，往往比导出后补救更省事。

## 和普通导出 SKP 有什么不同

| | `rsSuExport` | Rhino 普通导出 SKP |
| --- | --- | --- |
| 模型组织 | 普通物体先成 Block，再按图层套外层 Block；已有 Block 尽量保留共享和嵌套关系 | 直接交给 Rhino 的 SKP 导出器转换，组件结构取决于导出器 |
| 曲面处理 | 导出前主动提取或生成 Rhino 渲染网格，能提前把精度控制在 Rhino 一侧 | 由 SKP 导出器在写文件时处理 |
| 输出设置 | 固定导出 SketchUp 2016 格式，并把平面区域作为多边形 | 可在 Rhino 导出选项中选择支持的版本及相关设置 |

命令最后仍是调用 Rhino 的 SKP 导出器写文件。它多做的是导出前的 Block 整理和网格准备；临时 Block 不会留在当前 Rhino 模型里。无法网格化的对象会尝试按原始几何导出，过短曲线可能被忽略。若想直接把模型推送到运行中的 SketchUp，可使用 `rsSendToSU`。
