> 模块：组织与选择 / 图层

[← 返回命令目录](/commands/)

**功能**：隐藏（关闭）所选对象所在的所有图层

**调用**：在 Rhino 命令行输入 `rsCloseObjLayer`（命令行交互）

**交互流程**：

1. 命令行输入 rsCloseObjLayer
2. 选择要关闭图层的物体
3. 程序关闭这些物体所在图层（跳过锁定图层）

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：跳过已锁定图层；被锁定的图层不会被处理
