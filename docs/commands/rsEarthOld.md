# rsEarthOld · 旧版下载地形

> 模块：地形 / 获取与编辑

[← 返回命令完全手册](/RsTool命令手册)

**功能**：将框选下载得到的地形网格及其贴图写入当前文档

**调用**：在 Rhino 命令行输入 `rsEarthOld`（打开设置窗口）

**交互流程**：

1. 命令启动后弹出旧版地图窗体（MapDialog，WindowsForms，非模态）
2. 在地图窗体中框选区域并确认下载
3. 窗体将地形网格写入当前文档

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：旧版地形下载命令，已被 rsEarth 取代；属于遗留实现。
