# rsEmbedLinkedBlocks · 外链图块转嵌入

> 模块：辅助工具 / 块操作

[← 返回命令目录](/commands/)

**功能**：把当前文件里的外部链接图块转成嵌入图块，减少交付模型时对外部文件的依赖。

**调用**：在 Rhino 命令行输入 `rsEmbedLinkedBlocks`（命令行交互）

**交互流程**：

1. 先确认外链源文件能找到、图块内容已经正常加载，建议另存一份文件。
2. 直接运行命令，无需选择对象；工具处理文档中的外链定义，并继续检查使用中的嵌套链接。
3. 查看已转换数量和剩余外链数量，按命令行提示检查失败项，然后保存 3dm。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：转换的是图块定义，不是把实例炸开；已有块实例仍按图块组织。转为嵌入后，不再跟随外部源文件更新。源文件缺失、内容未加载等情况可能导致个别定义无法转换，不能看到命令结束就认为所有链接都已解除。无需设置窗口。
