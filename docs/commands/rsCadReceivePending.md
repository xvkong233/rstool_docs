# rsCadReceivePending · 手动接收 CAD 待传批次

> 模块：辅助工具 / 导入导出

[← 返回命令目录](/commands/)

**功能**：在 Rhino 中手动检查 CAD 已发送的待接收批次，将其导入当前文档。

**调用**：在 Rhino 命令行输入 `rsCadReceivePending`（命令行交互）

**交互流程**：

1. 先在 CAD 端通过 RSTool 传输工具发送对象，确保发送完成。
2. 切换到目标 Rhino 文档，运行 rsCadReceivePending，然后等待当前命令结束后的空闲接收。
3. 查看接收数量和传输编号；没有排队内容时会提示没有待接收的 CAD 批次。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：这里说的是在 Rhino 中执行，方向是 CAD → Rhino；不要与 CAD 端同名的接收命令混淆。正常情况下插件也会自动检查，本命令用于手动接收，不会催促 CAD 把未发送的对象发过来。源 CAD 和 Rhino 都必须设置有效单位，导入会按单位换算；同一文档已接收的批次不会重复导入。源对象与接收对象数量可能因格式转换不同，请检查图层、注解和几何。反向发送见 [rsSendToCAD](./rsSendToCAD)。无需设置窗口。
