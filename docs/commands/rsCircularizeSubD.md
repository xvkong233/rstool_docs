# rsCircularizeSubD · SubD 选区圆形化

> 模块：SubD辅助 / 编辑工具

[← 返回命令目录](/commands/)

**功能**：把选中的 SubD 顶点、边或面所对应的区域整理成圆形，适合圆孔、圆形端部等局部塑形。

**调用**：在 Rhino 命令行输入 `rsCircularizeSubD`（命令行交互）

**交互流程**：

1. 使用 Rhino 子对象选择方式选中 SubD 顶点、边或面，或运行命令后再选择。
2. 按 Enter 确认；工具按对象和连通区域分析，拟合平面并调整控制点。
3. 检查圆形化后的 SubD 和命令行报告；不合适可 Undo。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：请选择子对象，不是整个 SubD。每个区域至少需要 3 个控制点，且要能识别稳定边界、拟合稳定平面；退化或边界无法解析的选区会报错。边界控制点均匀排到圆周，区域内控制点按连接关系松弛；调整的是 SubD 控制网，不是新画一条精确 NURBS 圆。全部对象准备成功后才统一替换，验证失败不会只改其中一部分。无需设置窗口。
