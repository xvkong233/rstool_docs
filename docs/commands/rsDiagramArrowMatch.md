# rsDiagramArrowMatch · 分析箭头样式匹配

> 模块：视图出图 / 标注出图

[← 返回命令目录](/commands/)

**功能**：把一个 RSTool 分析箭头的样式批量刷给其他分析箭头，快速统一分析图表达。

**调用**：在 Rhino 命令行输入 `rsDiagramArrowMatch`（命令行交互）

**交互流程**：

1. 运行命令，先选择一个作为样式来源的 RSTool 分析箭头。
2. 再选择需要匹配样式的目标箭头，可多选，按 Enter 确认。
3. 查看成功和失败提示，检查目标箭头的显示效果。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：匹配内容包括宽度、箭头大小与样式、线型与比例、箭头位置及渐细设置；目标继续沿自己的路径生成，来源箭头不改。只识别带有 RSTool 分析箭头数据的对象，普通曲线或已丢失数据的几何不能直接匹配。同一箭头组会去重处理；个别目标失败会单独报告。无需数值参数窗口。
