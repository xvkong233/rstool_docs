# rsSectionPositionPanel · 建筑剖切面板

> 模块：视图出图 / 标注出图

[← 返回命令目录](/commands/)

**功能**：打开建筑剖切管理面板，并在各 Rhino 视口中独立管理建筑折线剖切的激活状态。

**调用**：在 Rhino 命令行输入 `rsSectionPositionPanel`（打开设置窗口）

**交互流程**：

1. 命令行输入 rsSectionPositionPanel，打开可停靠的“建筑剖切面板”
2. 面板列出当前文档中的建筑剖切线；状态列显示“●”时，表示该剖切已在当前活动视口中启用
3. 点击“新增剖切”，选择在 World XY 平面绘制折线 / Jog，或将已有的垂直 ClippingPlane 转换为建筑剖切线
4. 选择一条剖切后点击“激活并选择”，也可以直接双击列表行，在当前视口启用剖切并选中对应曲线
5. 使用 Move、Rotate、Gumball 或控制点调整剖切位置和折点，面板会自动更新位置与观察方向
6. 按需改编号、翻转观察方向、删除剖切，或关闭当前视口中的活动剖切

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 活动状态 | Active | status | — | ● / 空白 | ● 表示该剖切已在当前活动视口中启用；活动状态按视口分别保存。 |
| 剖面编号 | Reference | text | 自动生成 | 非空且唯一 | 用于识别剖切线；输入重复编号时会自动追加唯一后缀。 |
| 位置 | Position | text | 自动读取 | World XY 坐标 | 显示剖切曲线包围盒中心的 X、Y 坐标，移动曲线后自动刷新。 |
| 观察方向 | ViewDirection | text | 自动计算 | World XY 方向 | 根据剖切曲线起始切线与观察侧计算；可用“翻转方向”切换到另一侧。 |
| 新增剖切 | AddSection | button | — | 绘制折线 / 转换 ClippingPlane | 绘制时右键结束折线，再在观察侧指定深度；转换时只能选择法向与 World XY 平行的垂直 ClippingPlane。 |
| 改编号 | Rename | button | — | 单选 | 修改所选剖切的编号；不允许空值，重复编号会自动生成唯一后缀。 |
| 删除 | Delete | button | — | 单选 / 多选 | 删除列表中选中的一条或多条建筑剖切线。 |
| 激活并选择 | ActivateAndSelect | button | — | 单选 | 在当前活动视口启用所选剖切，同时选中其曲线，便于继续移动、旋转或编辑控制点。 |
| 翻转方向 | FlipDirection | button | — | 单选 | 反转所选剖切的观察侧，并立即更新剖切方向。 |
| 关闭当前剖切 | DeactivateCurrentViewport | button | — | 当前活动视口 | 只关闭当前活动视口中的建筑剖切，不删除剖切线，也不影响其他视口。 |

**备注**：## 使用要点

- 建筑剖切线是可编辑的 Rhino 曲线，可使用 Move、Rotate、Gumball 或控制点修改位置和折点；它并非普通的原生 ClippingPlane。
- 同一视口中采用互斥激活：启用一条剖切时，会关闭该视口原先的活动剖切；不同视口可以分别保存各自的活动剖切。
- 列表支持多选，但多选主要用于批量删除；改编号、激活、翻转方向等操作要求只选择一项。
- 将垂直 ClippingPlane 转换为建筑剖切线后，原 ClippingPlane 会被删除；新剖切会优先沿用其名称，并按场景范围估算初始深度。
- 面板会监听文档和对象变化，在 Rhino 空闲时自动刷新。新增、转换、激活、重命名、删除、翻转及关闭操作均可使用 Rhino Undo 撤销。

## 与 rsPolylineSection 的关系

`rsSectionPositionPanel` 使用与 `rsPolylineSection` 相同的建筑折线剖切系统，主要用于集中查看、维护剖切线，并按视口快速切换活动剖切。
