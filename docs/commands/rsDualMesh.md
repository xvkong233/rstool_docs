# rsDualMesh · 对偶网格

> 模块：几何 / 网格

[← 返回命令完全手册](/RsTool命令手册)

**功能**：将网格每个面转化为一个顶点的对偶网格

**调用**：在 Rhino 命令行输入 `rsDualMesh`（命令行交互）

**交互流程**：

1. 选择网格
2. 生成对偶网格（面中心 → 顶点）

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：无可调参数
