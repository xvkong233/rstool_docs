# rsLockObjLayer · 锁定所选对象图层

> 模块：组织与选择 / 图层

[← 返回命令目录](/commands/)

**功能**：选几个物体，就能把它们所在的图层一起锁住，方便继续处理其他内容。

**调用**：在 Rhino 命令行输入 `rsLockObjLayer`（命令行交互）

**交互流程**：

1. 运行命令，选择需要锁定其图层的对象，按 Enter 确认。
2. 工具按图层去重后锁定，命令行会提示处理结果。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：锁的是整个图层，不只是刚才选中的物体；同层其他对象也会被锁定。当前图层会跳过，想锁它请先切换当前图层。需要恢复时，可使用 [rsUnlockAllLayers](./rsUnlockAllLayers)。无需设置数值参数或打开窗口。
