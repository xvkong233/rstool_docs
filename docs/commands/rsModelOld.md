> 模块：资源库 / 模型库

[← 返回命令目录](/commands/)

> 右键点击工具栏中的 [rsModel](./rsModel) 按钮可运行本命令；这里显示的是它们共用的按钮图标。

**功能**：打开旧版模型库窗口，浏览并插入模型/构件

**调用**：在 Rhino 命令行输入 `rsModelOld`（命令行交互）

**交互流程**：

1. 命令行输入 rsModelOld
2. 创建并显示 rsModelDialogOld (WinForms) 窗口
3. 在旧版库浏览器中选择模型并插入

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：旧版命令，WinForms 实现；作为 rsModel 的回退
