# <span class="rstool-command-icon rstool-command-icon--heading" title="rsToolCN：工具栏图标" aria-hidden="true"><img class="rstool-command-icon__light" src="/command-icons/light/0990a32c-00d2-528d-9505-31928da21d44.png" alt="" width="48" height="48" loading="eager" decoding="async"><img class="rstool-command-icon__dark" src="/command-icons/dark/0990a32c-00d2-528d-9505-31928da21d44.png" alt="" width="48" height="48" loading="eager" decoding="async"></span> rsToolCN · 中文工具列

> 模块：辅助工具 / 系统工具

[← 返回命令目录](/commands/)

**功能**：显示 RSTool 2.0 中文工具列，并记住本机的语言选择。

**调用**：在 Rhino 命令行输入 `rsToolCN`（命令行交互）

**交互流程**：

1. 输入 `rsToolCN`。
2. 中文工具列显示后，直接点击需要的工具；下次用 `rsToolStart` 会优先沿用这个语言。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：只切换工具列语言，不改变 Rhino 的界面语言。英文工具列使用 `rsToolEN`。
