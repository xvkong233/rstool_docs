# rsScreenGif · 区域录屏 GIF

> 模块：效率工具 / 屏幕工具

[← 返回命令目录](/commands/)

**功能**：框选屏幕上的一块区域，把操作过程录成 GIF，适合演示命令或反馈问题。

**调用**：在 Rhino 命令行输入 `rsScreenGif`（打开设置窗口）

**交互流程**：

1. 运行命令，在录屏窗口设置帧率、输出宽度和是否包含鼠标。
2. 框选屏幕区域，等待 3 秒倒计时后开始录制。
3. 录制中可以暂停、继续或停止；Ctrl+Alt+F9 暂停/继续，Ctrl+Alt+F10 停止。
4. 停止后预览，需要时放弃重录；确认后保存 GIF，可打开文件或所在目录。

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 帧率 | fps | list | 15 FPS | 5 / 10 / 15 / 20 FPS | 越高越流畅，也会增加帧数、文件体积和编码开销。 |
| 输出宽度上限 | maximumWidth | list | 1280 px | 原始 / 1920 / 1280 / 960 / 640 px | 按比例缩小，不会把较小的录制区域放大。 |
| 包含鼠标光标 | includeCursor | bool | 开启 | 开启 / 关闭 | 需要演示点击和操作位置时建议开启。 |

**备注**：这是屏幕区域录制，不是 Rhino 渲染动画；录制范围内其他窗口、通知和敏感内容也可能被录进去。建议先整理桌面，再录制较短片段；编码期间可取消保存。
