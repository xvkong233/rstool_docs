# rsAxisLockBasis · 确认轴锁世界坐标基准

> 模块：效率工具 / 生产力

[← 返回命令目录](/commands/)

**功能**：将方向键轴锁定的基准确认为世界 XYZ 坐标，并输出当前使用的基准。

**调用**：在 Rhino 命令行输入 `rsAxisLockBasis`（命令行交互）

**交互流程**：

1. 运行命令，查看世界坐标基准提示。
2. 需要开启或关闭方向键约束时，使用 rsAxisLock。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：当前实现只支持 World，不提供 CPlane 或自定义坐标选项，也不会修改 Rhino 当前工作平面。该命令不代替轴锁开关，无需设置窗口。
