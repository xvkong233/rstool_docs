> 模块：辅助工具 / 系统工具

[← 返回命令目录](/commands/)

**功能**：在系统文件管理器中打开 RSTool 插件安装目录

**调用**：在 Rhino 命令行输入 `rsToolLocation`（命令行交互）

**交互流程**：

1. 命令行输入 rsToolLocation
2. 获取插件安装目录路径
3. 在资源管理器中打开该目录

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。
