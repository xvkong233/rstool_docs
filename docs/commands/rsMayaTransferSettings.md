# rsMayaTransferSettings · Rhino-Maya 传输设置

> 模块：辅助工具 / 导入导出

[← 返回命令目录](/commands/)

**功能**：打开 Rhino-Maya 传输设置窗口

**调用**：在 Rhino 命令行输入 `rsMayaTransferSettings`（打开设置窗口）

**交互流程**：

1. 命令行输入 rsMayaTransferSettings
2. 弹出 Rhino-Maya 传输设置窗口
3. 配置传输参数后关闭窗口

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：窗口已打开时再次运行会将其置顶，不会重复创建。
