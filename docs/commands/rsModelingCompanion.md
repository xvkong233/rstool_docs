# rsModelingCompanion · 建模陪伴

> 模块：效率工具 / 生产力

[← 返回命令目录](/commands/)

**功能**：切换建模陪伴助手的显示 / 隐藏

**调用**：在 Rhino 命令行输入 `rsModelingCompanion`（命令行交互）

**交互流程**：

1. 命令行输入 rsModelingCompanion
2. 桌面助手出现；再次运行可暂时隐藏，再运行一次恢复

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：切换式命令：重复运行可在显示/隐藏间切换。完整设置项（形象、性格、AI 端点、功能开关等）见 rsModelingCompanionSettings。

> ⚠️ **首次使用前必做**：先在 `rsModelingCompanionSettings` 中填写 AI 端点（默认 DeepSeek）与 API Key，否则助手无法对话或建模。

## 它是什么

植入 Rhino 桌面的 AI 建模陪伴助手——一只可常驻屏幕的虚拟宠物。运行命令后出现在屏幕角落，既能陪你聊天，也能直接动手改你的 Rhino 模型，不占用建模视口，可随时隐藏或恢复。

## 三种工作模式

### 1. 对话问答（Chat）
用自然语言问 Rhino / Grasshopper / 建筑相关问题，例如「怎么快速建一个螺旋楼梯」「某个命令的快捷键是什么」「幕墙单元怎么参数化」。它会结合当前文档上下文作答。

### 2. 直接建模（Agent）
用口语下指令，它识别动作意图后生成安全建模计划并预览，确认后直接写入 Rhino。动作白名单（单次最多 12 个，带数量与参数范围安全检查）：

- 创建类：create_box（方体）、create_random_boxes（随机排布方体）、create_cylinder（圆柱）、create_sphere（球体）、create_polyline（折线）、create_extrusion（挤出体）、create_floor_stack（楼层堆叠）、create_facade_grid（幕墙网格）
- 编辑选中类：move_selected（移动）、copy_selected（复制）、rotate_selected（旋转）、scale_selected（缩放）

典型说法：「帮我画一个半径 5 的球体」「把选中的对象往上移 3 米」「在这一排盒子上挤出楼板」。

### 3. 生成 Rhino Python 代码（Code）
识别「写代码 / 脚本 / 批量 / 阵列 / 循环」等需求，生成可执行的 Rhino Python 脚本（优先 rhinoscriptsyntax，也可用 RhinoCommon），可结合你贴的参考图理解意图。适合批量处理、阵列、参数化等脚本任务。

## 专注功能（Focus）

内置番茄钟式专注会话：可开始 / 暂停 / 恢复 / 取消 / 查看状态一段专注时间，并给任务起名。专注期间助手进入「专注」状态推动你完成当前任务；完成后累积积分、连续天数与成就，帮助保持工作节奏。适合「这段时间只把这块幕墙推完」的场景。

## 上下文与增强

- Rhino 上下文感知：自动读取当前文档与选中对象（最多 64 个），让回答和建模贴合实际场景。
- 项目记忆：跨会话记住项目偏好与约定（可在设置关闭）。
- 联网搜索：需要时效信息时自动联网检索（可在设置关闭）。
- Agent 视觉校验：建模动作执行后自动校验结果是否合理。
- 参考图理解：可贴图 / 截图辅助它理解建筑参考。

## 形象与性格

- 6 种可选性格：温柔陪伴、专业建筑师、元气搭档、严格监工、霸道总裁、安静助手——决定语气与反馈风格。
- 可换宠物形象，调节大小、透明度、是否置顶、点击穿透、位置锁定、空闲闲聊频率等。
- 长时间未保存（约 1 小时）会主动提醒你按 Ctrl+S。
