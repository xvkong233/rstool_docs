# rsLayFlat · 一键放平

> 模块：几何 / 对象变换

[← 返回命令目录](/commands/)

**功能**：将对象按指定面放平

![Rhino Perspective 视口：上方一个倾斜悬空的立方体方块，下方平放在地面的同一方块，中间黑色箭头从上指下示意 rsLayFlat 平放过程](../assets/rsLayFlat/image1.png)
*图 1：rsLayFlat 平放效果。Rhino Perspective 视口（左上角 Perspective 标签，左下/右下角红绿坐标轴）里有两个同一立方体方块：上方一个白色+浅灰两色面的方块在空间倾斜悬空（不是水平姿态），下方是同一个方块已经被按用户指定的目标面自动计算支撑点与面法向后旋转放平——白色顶面水平朝上、灰色前面垂直立在地上、整体端正水平；视口中部有一个黑色箭头由上方指向下方，标示“倾斜→平放”的过程。命令流程为：选择对象上的目标面 → 自动计算支撑点与面法向 → 将对象旋转放平到该面*

**调用**：在 Rhino 命令行输入 `rsLayFlat`（命令行交互）

**交互流程**：

1. 选择对象上的目标面
2. 自动计算支撑点与面法向
3. 将对象旋转放平到该面

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：参照对象、引用对象与图块定义内的几何不可放平。
