# rsPointDim · 逐点标注

> 模块：视图出图 / 标注出图

[← 返回命令目录](/commands/)

**功能**：使用当前图层和当前标注样式生成连续线性 / 对齐尺寸，或将已有尺寸合并、拆分为新的尺寸对象。

**调用**：在 Rhino 命令行输入 `rsPointDim`（打开设置窗口）

**交互流程**：

1. 命令行输入 rsPointDim，打开非模态“逐点标注”面板；再次运行会将已打开的面板置于前方
2. 选择方向：自动、水平、垂直或对齐标注；面板同时显示当前 Rhino 标注样式
3. 点击“逐点标注”，依次指定第一个点、第二个点和标注线位置
4. 继续点取更多标注点；橙色动态预览会按标注方向排序并显示相邻尺寸段
5. 按 Enter 或右键完成，使用 Undo 选项撤回上一点，按 Esc 取消整次操作
6. 也可点击“合并标注”合并连续尺寸，或点击“拆分标注”在一个或多个内部点拆开现有尺寸

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 方向 | Direction | select | 对齐标注 | 自动 / 水平 / 垂直 / 对齐标注 | 水平和垂直使用活动视口工作平面的 X/Y 轴；自动模式根据标注线放置方向选择水平或垂直；对齐模式锁定第一、第二点形成的方向。 |
| 标注样式 | DimensionStyle | status | 当前 Rhino 标注样式 | 只读 | 面板会自动显示当前文档的标注样式；新建尺寸使用该样式。若要更换，请先在 Rhino 中切换当前标注样式。 |
| 逐点标注 | PointDimension | button | — | 连续点取 | 从多个尺寸点生成按方向排序的连续尺寸段，结果写入当前图层。 |
| 合并标注 | Merge | button | — | 至少两条线性或对齐标注 | 所选尺寸必须类型一致、共面、同向、位于同一标注线上且区间首尾连续；不能存在间隙或重叠。 |
| 拆分标注 | Split | button | — | 一条线性或对齐标注 | 在尺寸区间内部拾取一个或多个互不重合的拆分点，将原标注替换为多个连续尺寸段。 |

**备注**：

## 四种标注方向

- **自动**：根据标注线相对前两个尺寸点的放置方向，在工作平面的水平与垂直标注之间自动选择。
- **水平**：沿活动视口工作平面的 X 轴测量；拾取点会投影到当前工作平面。
- **垂直**：沿活动视口工作平面的 Y 轴测量；拾取点会投影到当前工作平面。
- **对齐标注**：以第一点到第二点的空间方向作为锁定轴，后续拾取点沿该轴形成尺寸站点，适合斜向或空间方向的连续标注。

## 合并与拆分

- 合并仅接受可编辑且未锁定、非参照的线性 / 对齐标注；线性与对齐标注不能混选。新标注继承第一条标注的对象属性，并恢复为自动测量文字。
- 拆分时原标注会暂时隐藏；取消操作会重新显示。生成的各段继承原对象属性，尺寸文字同样恢复为自动测量值。
- 新建、合并和拆分均写入 Rhino Undo 记录；写入失败时会回滚已创建或删除的对象。

面板绑定打开它的 Rhino 文档。切换到其他文档或正在运行另一条 Rhino 命令时，需先结束当前命令并返回对应文档；关闭文档时面板会自动关闭。
