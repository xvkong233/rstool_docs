# rsAxisLock · 方向键轴锁定开关

> 模块：效率工具 / 生产力

[← 返回命令目录](/commands/)

**功能**：开启或关闭方向键轴锁定，在带基点的取点过程中沿世界 X、Y、Z 轴约束方向。

**调用**：在 Rhino 命令行输入 `rsAxisLock`（命令行交互）

**交互流程**：

1. 运行命令，按命令行提示确认轴锁定已开启；再次运行即可关闭。
2. 在有基点的取点阶段，按右方向键锁 X、左方向键锁 Y、上方向键锁 Z。
3. 按下方向键解除当前轴约束，再继续取点。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：轴向固定使用世界坐标，不随当前工作平面旋转。首次无保存设置时默认关闭，之后会记住开关状态。不是所有鼠标操作都适用：没有可用的带基点取点过程时不会接管方向键。若未生效，可运行 [rsAxisLockStatus](./rsAxisLockStatus) 查看状态。无需设置窗口。
