# rsFlattenBlockElevation · 图块统一标高

> 模块：辅助工具 / 块操作

[← 返回命令目录](/commands/)

**功能**：将所选图块实例替换为独立的拍平副本；其中全部叶子物体位于指定的世界 Z 标高，未选实例和原块定义保持不变。

**调用**：在 Rhino 命令行输入 `rsFlattenBlockElevation`（命令行交互）

**交互流程**：

1. 命令行输入 rsFlattenBlockElevation
2. 选择一个或多个需要统一标高的图块实例；支持预选和组选择，不支持子对象选择
3. 输入目标世界 Z 标高；直接回车可沿用上一次输入值，首次默认为 0
4. 命令递归读取每个图块及其嵌套图块，把全部叶子物体投影到该世界 Z 标高
5. 为每个所选实例创建独立的新块定义，并用新块替换原实例
6. 处理完成后自动选中新块，命令行报告处理数量和目标标高

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 目标标高 | TargetElevation | double | 上次输入值（首次为 0） | 有效有限数值，单位随当前 Rhino 文档 | 所有图块内容的世界 Z 坐标都会统一为该值；世界 X、Y 坐标保持不变。 |

**备注**：## 处理规则

- 命令按**世界坐标**投影：保留物体的世界 X、Y 位置，将所有点的 Z 坐标统一为目标标高。图块原有的平移、旋转、缩放及嵌套变换会先合并到最终几何中。
- 嵌套图块会递归展开为最底层物体，新块定义中不再保留嵌套引用；叶子物体的图层、颜色、材质等对象属性会随副本保留。
- 每个所选图块实例都会创建独立的新定义，名称采用 `原块名_Flattened`；若名称已存在，会自动添加 `_1`、`_2` 等后缀。原块定义以及其他未选中的共享实例不会被修改。
- 新块的插入点保留原实例插入点的世界 X、Y，并移动到目标 Z 标高。

## 注意事项

- 本命令适合整理二维图例、平面家具、CAD 导入块等本应位于同一标高的图块。三维实体、非平面曲面或其他不能承受退化投影的几何可能拍平失败，不建议将它用于保留三维形体。
- 目标标高必须是有效的有限数值。空块、失效定义、循环嵌套或包含无法复制 / 投影的物体时，命令会停止并输出原因。
- 命令会先准备全部所选图块；任一图块无法处理时，不会修改文档。替换过程中若发生异常，会尝试恢复已替换实例并清理新定义。
- 整个操作写入 Rhino Undo 记录，可在完成后撤销。
