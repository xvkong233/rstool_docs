# RSTool 2.0：命令变化与对照

根据 2026-11-11 的 2.0 源码核对。升级后找不到原来的命令，可以先在这里看它现在从哪里进入；实际可用功能以所装版本为准。

## 先看这几个变化

- 墙体、门窗、幕墙和电梯用同一套面板选择二维或三维；双跑、多跑楼梯也整合了原来的二维命令。
- 参数对象选中后到属性面板继续修改，部分旧编辑命令改成了 Rhino 原生操作或面板按钮。
- 资源库、工作室和部分工具面板放到了 RSTool 客户端里，使用时保持客户端运行并登录。
- 旧命令名不会自动变成兼容别名。自己设置的工具栏宏和快捷键，需要改成现在的入口。

## 改成原生操作或面板设置

| 旧入口（点击查看历史页） | 现用入口 / 操作 |
| --- | --- |
| [`rsDeleteWall2D`](/commands/rsDeleteWall2D) | 选择墙体后使用 Rhino 的 Delete，关联交接会随删除更新。 |
| [`rsMoveOpening2D`](/commands/rsMoveOpening2D) | 选择门窗后使用 Rhino 的平面 Move，位置变动由关联同步处理。 |
| [`rsEditOpening2D`](/commands/rsEditOpening2D) | 选中门窗或电梯，在属性面板中调整对应的建筑参数。 |
| [`rsDeleteOpening2D`](/commands/rsDeleteOpening2D) | 选中门窗后使用 Rhino 的 Delete，宿主墙体的开口会同步更新。 |
| [`RSToolActivateLicense`](/commands/RSToolActivateLicense) | 在 RSTool 客户端中登录并完成设备授权；2.0 不再使用旧的独立激活命令。 |
