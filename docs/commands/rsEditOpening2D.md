::: details 查看 1.x 历史说明

> 本节的图标、截图、参数与操作流程均为旧版资料。

**功能**：修改所选门窗/电梯的参数（尺寸、开启方向、电梯尺寸等）并重生成符号与墙洞

**交互流程**：

1. 命令行输入 rsEditOpening2D
2. 选择要编辑的门窗/电梯
3. 在选项行修改参数（门宽/窗宽/开启角度/翻转方向/电梯宽深等，随类型变化）
4. 回车确认，实时预览更新并重开墙洞

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：参数项随开口类型动态变化，默认值取该开口的现有参数（非固定数值输入）
