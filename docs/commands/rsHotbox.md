# rsHotbox · 热盒

> 模块：辅助工具 / 系统工具

[← 返回命令目录](/commands/)

**功能**：在 Rhino 活动视口内围绕鼠标位置呼出径向命令菜单（默认轻点 Ctrl 触发），点击/数字键选择对应方向槽或子环命令后执行；再次触发或 Esc/右键关闭

![rsHotbox 径向命令菜单工作示例：中心为「< 网格」表示当前选中 SE 子环(网格)；环绕中心 8 个方向槽位按 N/NE/E/SE/S/SW/W/NW 排序，依次为[1]建筑 / [2]二维建筑 / [3]曲线 / [4]网格 / [5]选择 / [6]图层 / [7]视角 / [8]辅助，当前 4 方向「网格」chip 高亮橙色；下方二级面板展开 SE 子环 8 项命令：网格框架(1) / 网格工具(2) / 闭合网格外器(3) / 按材质合并网格(4) / 统一四边面网格(5) / 对偶网格(6) / 三角重构曲面(7) / 按曲率减网格面(8)；底部状态栏提示"1-8 选择 · 方向键导航 · 回车执行 · 滚轮切子层 · Esc 关闭"](../assets/rsHotbox/image1.png)
*示例：当选中 SE 方向「网格」chip 后，下方外环自动展开 8 个网格类二级命令，每个对应一个 RSTool 网格工具，数字键 1-8 直接选择/回车执行*

**调用**：在 Rhino 命令行输入 `rsHotbox`（命令行交互）

**交互流程**：

1. 默认轻点 Ctrl 呼出热盒（可在设置中改为其他触发方式）
2. 热盒围绕鼠标位置显示 8 个方向槽位，悬停子环槽位自动展开子命令
3. 点击命令槽执行命令；点击中心切换方案，深层子环时点击中心返回上一层
4. 打开热盒后可按数字键 1-8 快速选择命令，回车执行，Esc 关闭
5. 再次运行 rsHotbox 或按 Esc / 鼠标右键关闭热盒

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：热盒（Hotbox/Pie Menu）是把常用的 RSTool 与 Rhino 命令集中到一个 8 方向径向菜单里，通过鼠标悬停弹出或按数字键快速键选；不挡视线、不打断节奏，特别适合建模熟练期的'少动键、多用腕'场景。

核心结构：8 个主方向槽位固定不变，按东南西北 N/NE/E/SE/S/SW/W/NW 排序，分别对应 1-8 数字快捷键。每个主方向槽位下可放'命令/宏/子环'三种动作类型之一；选'子环'则该方向会再展开一圈二级方向槽（8 个方向），子环之上还能再嵌一层，达到最多两层嵌套。中心位置是方案切换/返回上一层按钮，配合滚轮可快速在多套方案（Profile）之间来回切换，方案之间状态完全独立。

默认方案与目录结构（与截图一致）：主环按 [1]建筑 / [2]二维建筑 / [3]曲线 / [4]网格 / [5]选择 / [6]图层 / [7]视角 / [8]辅助 分类组织，每个主环的二级子环按场景细分 8 项网格 / 墙体 / 曲线 / 视角常用命令；可按个人习惯用 rsHotboxSettings 自行调整顺序、覆盖、换类型（命令→宏→子环都可）。

交互 5 类：①鼠标悬停（hover）—— 自动展开该方向子环（延迟约 100ms 防止误触）；②鼠标点击 —— 单击执行对应命令、单击中心切换方案或在深层子环时返回上一层；③键盘 —— 数字键 1-8 直选方向、回车执行当前选中项、Esc 关闭、方向键←↑↓→在 8 个方向间跳转；④滚轮 —— 切换方案（在两套不同工作流之间快速切换）；⑤右键/Esc —— 不执行直接关闭。所有交互都没有模态窗口，停用即消失，不阻塞 Rhino 主流程。

典型使用场景：①学习期 —— 把平时点不到的隐藏命令（如 rsKeySettings、rsDiagramArrowEdit）放到热盒 1 号位减少记忆负担；②建模期 —— 多弧形曲面幕墙建模时把'延伸曲面/曲面合并/重建 UV'等一连串操作放进一个子环，连续触发无窗口打扰；③出图期 —— 把'图层切换/快速锁定/视图命名保存/截图'等视图相关命令集中到一个方案，滚轮一键切工作流；④录屏/演示 —— 数字键 1-8 直接选方向回车执行，避免鼠标飘移，看上去干净。

热盒与其他应用的关系：①只在 Rhino 当前获得焦点的活动视口里响应（后台监听逻辑在 rsHotboxSettings 里启用），命令行/Eto 对话框/WebView 等不会接管、不会误触发；②外观可跟随 Rhino 主题或强制深/浅，不抢眼但清楚；③执行前会自动取消当前 Rhino 命令，避免'在 _Line 中再开热盒'的卡死局面；④运行期间鼠标光标被锚定在该热盒方案切换层级内，不影响 Rhino 视口的常规选择/平移/缩放。
