# rsDisplacementToMesh · 置换贴图转真实网格

> 模块：几何 / 网格

[← 返回命令目录](/commands/)

**功能**：结果网格以 <源对象名 或 "Displaced">_Displaced 命名加入当前文档，并自动选中；同时保留源对象（除非勾选「隐藏原物体」） 关闭结果对象的置换显示（Displacement.On=false 并清除子项），避免与真实几何叠加 克隆一份不含置换的渲染材质（命名为 "Baked Displacement" 或 原名+(Baked)），挂到结果上，保证导出/渲染一致 写入 UserString 便于追溯：RSTool.Type=DisplacementMesh、RSTool.SourceObjectId（源对象 GUID）、RSTool.FaceCount、RSTool.IsClosed、RSTool.SelfIntersectionCount 预览阶段用橙色半透明 DisplayConduit 实时叠加显示；最终网格按「最大面数」受控生成，可中途取消

**调用**：在 Rhino 命令行输入 `rsDisplacementToMesh`（打开设置窗口）

**交互流程**：

1. 命令行输入 rsDisplacementToMesh，按提示选择要烘焙的 Mesh / Brep / Surface / SubD 对象（支持预选，命令前先选中即可）
2. 自动读取该对象的置换（displacement）/ 凹凸（bump）材质设置；若读取失败则自动回退为「手动高度贴图」模式，需自行指定高度图
3. 弹出「置换贴图转真实网格」对话框，在「基础参数 / 高级参数」两个标签页中设置来源、置换范围、生产输出与精度限制
4. 任一参数变更后约 0.35 秒自动计算安全预览（逐顶点置换，最多 2 万面，以橙色半透明网格实时显示）
5. 点「生成最终网格」生成受控的最终网格（严格遵守「最大面数」上限，可中途取消）；若未开启「均匀加厚」且质量报告存在警告，会弹窗确认是否仍加入文档
6. 结果以 <原名>_Displaced 命名加入文档并自动选中；勾选「隐藏原物体」则隐藏源对象，取消则不隐藏并重新显示

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 贴图来源 | Texture source | list | 自动（置换/凹凸） | 自动（置换/凹凸）/ 手动高度贴图 | 切换为「手动高度贴图」后才能选择高度贴图文件 |
| 高度贴图 | Height bitmap | file | （手动模式选择） | .png .tif .tiff .jpg .jpeg .bmp | 仅「手动高度贴图」模式可用，通过「选择…」按钮载入灰度高度图 |
| 映射通道 | Mapping channel | int | 自动读取（手动默认 1） | 1–99 | 高度图取样所用的 UV 通道编号 |
| 质量预设 | Quality preset | list | 标准（推荐） | 快速（预览优先）/ 标准（推荐）/ 精细 / 自定义 | 切换预设会套用对应的采样间距、细化、焊接、平滑与面数/内存上限；修改高级参数会自动切到「自定义」 |
| 黑色高度 | Black height | double | 随预设/自动 | -对象尺寸×10 … +对象尺寸×10（模型单位） | 高度图中黑色像素对应的位移量；正为沿法线向外 |
| 白色高度 | White height | double | 随预设/自动 | -对象尺寸×10 … +对象尺寸×10（模型单位） | 高度图中白色像素对应的位移量 |
| 反向置换 | Reverse direction | toggle | false | 开 / 关 | 反转置换方向（黑/白高度对调，向内/向外翻转） |
| 采样间距 | Sweep pitch | double | 随预设 | ≥ 模型容差 … 对象尺寸×10 | 网格边采样步长；越小细节越高但越慢 |
| 均匀加厚 | Solidify | toggle | false | 开 / 关 | 把薄壳置换结果封闭为实体并给出厚度；开启后自动开启并锁定「自交检查」 |
| 厚度 | Thickness | double | 随预设（开启 Solidify 后可设） | ≥ 模型容差 … 对象尺寸×10 | 仅开启「均匀加厚」时可编辑，实体壳的厚度 |
| 隐藏原物体 | Hide original | toggle | false | 开 / 关 | 生成后隐藏源对象；取消则保留并重新显示 |
| 自交检查 | Self-intersection check | toggle | false | 开 / 关（开 Solidify 时强制 true） | 检测置换表皮是否自交；开 Solidify 时被锁定开启 |
| 细化次数 | Refine steps | int | 随预设 | 0–8 | 在采样后做几轮边细分细化，提升细节 |
| 细化敏感度 | Refine sensitivity | double | 随预设 | 0–1 | 控制细化对曲率变化的敏感程度 |
| 焊接角度 (度) | Post-weld angle | double | 随预设 | 0–180 | 焊接法线夹角小于该值的相邻面，平滑接缝 |
| 平滑次数 | Fairing passes | int | 随预设 | 0–100 | 生成后对网格做几轮光顺，减少锯齿 |
| 最大面数 | Face limit | int | 随预设 | 1000–50000000 | 最终网格面数硬上限，防止结果失控卡死 |
| 内存上限 (MB) | Memory limit (MB) | int | 随预设 | 64–32768 | 生成过程内存占用上限 |

**备注**：置换贴图 vs 真实网格：Rhino 的置换只在渲染时显示起伏，本命令把它「烘焙」成真正可编辑、可布尔、可导出的网格几何，适合用于加工 / 3D 打印 / 下游软件 来源自动检测：优先读取对象的 PBR 置换（displacement）或凹凸（bump）贴图；当检测到疑似法线图（法线图不是高度图）时状态栏标橙警告，此时应切「手动高度贴图」指定正确的灰度高度图 预览与最终分离：预览最多 2 万面、可快速迭代参数；最终网格严格遵守「最大面数」，细节更完整但更耗时，且可取消 生产风险：薄壳置换易出现自交/翻面，未开启「均匀加厚」时若质量报告存在警告，会弹窗提示，确认后才加入文档；开启「均匀加厚」可封闭为实体并强制自交检查 性能与失控防护：采样间距越小、细化次数越多，细节越高但耗时越长；「最大面数」与「内存上限」是防止大模型卡死 / 爆内存的两道保险 追溯与协作：输出对象带 RSTool.Type=DisplacementMesh 等 UserString，可用脚本按类型筛选、按 SourceObjectId 反查源对象
