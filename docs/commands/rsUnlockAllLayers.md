# rsUnlockAllLayers · 解锁全部图层

> 模块：组织与选择 / 图层

[← 返回命令目录](/commands/)

**功能**：一键解锁当前文件的全部图层，同时清除图层的持久锁定状态。

**调用**：在 Rhino 命令行输入 `rsUnlockAllLayers`（命令行交互）

**交互流程**：

1. 运行命令，工具会遍历当前文档的图层并解除锁定。
2. 查看命令行处理结果，再选择或编辑原先因图层锁定而无法操作的对象。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：这不是「只解锁可见图层」，会处理整份文件的图层。它解除的是图层锁定，不会把单独锁定的对象也自动解锁。父层的继承关系会恢复；无需打开设置窗口。
