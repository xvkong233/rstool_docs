# rsNewLayer · 新建图层

> 模块：组织与选择 / 图层

[← 返回命令完全手册](/RsTool命令手册)

**功能**：创建（或在已存在时复用）新图层并设为当前图层

**调用**：在 Rhino 命令行输入 `rsNewLayer`（命令行交互）

**交互流程**：

1. 命令行输入 rsNewLayer
2. 输入新图层名称
3. 在当前图层下创建子图层（或同级）并设为当前图层

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 新图层名称 | layerName | text |  |  | RhinoGet.GetString；若同名图层已存在则直接设为当前图层 |

**备注**：若当前图层为子图层，则在该父图层下创建嵌套子图层
