# rsSimpleSculptor · 快速雕刻工具

> 模块：几何 / 网格

[← 返回命令目录](/commands/)

**功能**：原地雕刻后的网格（顶点位移）；取消则恢复原网格

*快速雕刻工具：以 hybrid 模式（命令行 + Eto 面板）选中网格后激活，左键拖动即时位移顶点；面板调节笔刷半径/位移量/强度/硬度/曲线形式/镜像/Alpha 贴图等 11 个参数。*

**调用**：在 Rhino 命令行输入 `rsSimpleSculptor`（命令行交互）

**交互流程**：

1. 选择要雕刻的网格
2. 打开雕刻面板并激活 GetPoint
3. 按住左键在网格上拖动雕刻（隆起/下降/整平）
4. 在面板调整笔刷半径/强度/硬度/曲线/镜像等
5. 回车或“完成”结束写入，或“取消”恢复原网格

## 笔刷 5 要素详解

每次落笔的位移量由这 4 个数值 + 1 个曲线形式共同决定。

- **笔刷半径 Brush radius**（1.0 / 0.001–100000）：受影响顶点集的判定距离。每个顶点按其到笔刷中心的距离 a，半径 R 内的顶点为潜在受影响集合；距离越大影响越小（按强度衰减）。
- **位移量 Amount**（0.1 / 0–100000）：单笔每帧在该顶点上的位移大小；隆起/下降模式生效，**整平模式自动禁用**。
- **强度 Strength**（0.55 / 0–1）：笔刷整体作用强度倍乘；越大则同等位移量下结果凸起越夸张。
- **硬度 Hardness**（0.35 / 0–1）：在笔刷半径内的衰减曲线陡峭度；0 = 全范围内柔和过渡、1 = 中心集中、近乎阶梯式只影响中心。
- **曲线形式 Profile**（圆润 Smooth / 线性 Linear / 尖峰 Sharp / 宽缓 Broad / 拱形 Dome / 阶梯 Terrace 6 种预定义衰减曲线）：每种曲线影响"距离 a vs 位移系数 f(a/R)"映射——圆润最常用，强弱过渡自然；线性即距离=比例；尖峰中心突起尖锐、边缘几乎不变；宽缓大半径仍可拉到峰值；拱形双向曲线（中心低、向外先升后降）；阶梯强调等高线感。

实测常用两套：①**细致塑型**——半径 0.3 / 强度 0.4 / 硬度 0.6 / 曲线 圆润或尖峰；②**山体大面起伏**——半径 5 / 强度 0.7 / 硬度 0.3 / 曲线 宽缓或拱形。

## 镜像雕刻

勾选「镜像笔刷 Mirror brush」后开启 X / Y / Z 对称：每次落笔会同时在镜像平面另一侧写一笔；可叠加多面镜像（X+Y 四面对称、XYZ 全八分对称）。

- **镜像轴 Mirror axis**：X（默认）/ Y / Z，分别绕 X/Y/Z 轴镜像
- **镜像平面位置 Mirror plane offset**（0.0）：镜像平面沿轴的偏移量；默认值 0 即全局中点位置；可设到任意位置同步雕刻多个对称中心

镜像对公共建筑山墙面（中轴对称）、地形地势（X+Y 双轴）、复杂几何主体（绕 Z 全对称）非常有效。

## 黑白贴图 Alpha map

「Black map / Alpha map」是把黑白 PNG/JPG 当作笔刷遮罩来用：黑=0%位移、白=100%；支持 png/jpg/jpeg/bmp/tif/tiff。常用场景：
- 在墙体上做凹凸字、凹凸 logo
- 地形起伏按贴图斑块引导（河流/植被）
- 镂空雕花（贴图背景=黑掩模）

载入后在笔刷半径内叠乘该遮罩；点击「清除贴图」恢复无遮罩笔刷。

## 固定边界 / 整平模式

- **常定边界 Preserve boundary**：网格轮廓顶点不参与位移（默认勾选）。取消勾选会让边线也被拖动——一般用于无明确边界的自由表面。
- **整平 Flatten 模式**：把圆滑区域拉平到当前笔刷中心点所在切面高度，**移除曲率而非漂移顶点**（其它模式会沿法向推拉）。常用于平面化山顶、大面积找平。

## 撤销 / 取消 / 实时预览

- **Ctrl+Z 撤销上一笔**：单笔粒度撤销；每落一次鼠标为一个撤销单位（含来回抖动）
- **「完成」Bake 写入原始网格**；**「取消」**丢弃全部笔触恢复原状
- 持左键移动 = 连续落笔；松开 = 当前笔触结束
- 启用「细分密度」/「最小细分边长」可在稀疏区域细分加密，让雕刻细节更圆滑（无原始细分则雕刻会暴露三角面片错切）
- 跨网格可继续拖入新网格雕刻（不打断当前会话）

完成雕刻后可继续用 rsMeshRelax、rsMeshOffset、rsTesselateNurbs 等后续工具做松弛、偏移、面板化等操作。
