# rsSettingsTransfer · Rhino / RSTool 设置迁移

> 模块：效率工具 / 生产力

[← 返回命令目录](/commands/)

**功能**：导出 Rhino / RSTool 设置包（.rssettings），或将包内设置迁移到目标电脑；导入前自动备份原设置，关闭全部 Rhino 后写入并在下次启动时生效。

**调用**：在 Rhino 命令行输入 `rsSettingsTransfer`（命令行交互）

**交互流程**：

1. 在来源电脑输入 rsSettingsTransfer，选择“导出 / Export”。
2. 选择是否包含 RSTool 保存的 API Key、Token 和代理凭据，默认“不包含”；选择保存位置，生成 .rssettings 设置包。
3. 将设置包复制到目标电脑。目标电脑需安装相同 Rhino 主版本及相应插件，然后运行 rsSettingsTransfer，选择“导入 / Import”。
4. 选择设置包，查看来源版本、文件数量、凭据状态和外部资源数量，确认导入。命令会先自动备份目标电脑当前设置。
5. 保存当前模型，关闭所有 Rhino 窗口，包括其他正在运行的 Rhino 8 / 9；设置会在它们退出后写入，再次启动 Rhino 时生效。

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 操作 | Action | 命令行选项 | 需选择 | Export（导出） / Import（导入） | 在来源电脑导出，在目标电脑导入，也可以用于同一台电脑的设置备份。 |
| 包含 API 凭据 | IncludeApiCredentials | 导出确认 | 否 | 是 / 否 / 取消 | 选“否”会去除 RSTool 配置中的 API Key、Token 和代理凭据，导入时保留目标电脑现有凭据；选“是”会将凭据以可迁移的明文放进设置包。 |
| 设置包文件 | PackageFile | 文件选择 | 导出时自动生成带日期的文件名 | .rssettings | 导出选择保存位置；导入选择已有设置包。确认窗口会显示包的来源与内容概况。 |
| 立即退出当前 Rhino | ExitNow | 导入后确认 | 由用户选择 | 是 / 否 | 选“是”会请求退出当前 Rhino；选“否”可稍后自行退出。无论选哪项，都需关闭所有 Rhino 窗口后才会执行导入。 |

**备注**：

## 可以迁移哪些内容

- Rhino 的选项、显示模式、界面布局、工具列和可读取的插件设置。
- Rhino 的默认模板、环境贴图、自定义模板，以及设置中能识别并找到的外部显示贴图和工具列文件；导入时会调整这些打包资源的路径。
- RSTool 的常用配置，以及 Profile Director、建模陪伴动作和工作流、待办、思维导图等设置数据。

## 换电脑时怎么用

在旧电脑导出一个设置包，复制到新电脑，再导入即可。Rhino 主版本必须一致，例如 Rhino 8 的包只能导入 Rhino 8，不能直接导入 Rhino 9。设置迁移不会安装插件，也不会把整个本地模型库或材质库一起搬走，这些内容需要另外复制；迁移后检查并调整资源库目录。RSTool 授权文件不在导出范围内，目标电脑需单独完成授权。

导入会替换包内对应的目标设置。命令会先自动备份，并在完成提示中给出备份文件位置；确认导入后，先保存模型再关闭全部 Rhino。刚确认时只是排队，当前窗口的设置不会立即切换。

## API 凭据与导出提示

只迁移界面和使用习惯时，保持默认“不包含 API 凭据”即可。想连同自己的 API Key、Token、代理凭据一起迁移，可以选“是”，但设置包内会包含明文凭据，请妥善保管，不要公开分享。

导出结果中的警告会说明无法读取或找不到的资源，建议检查后再使用设置包。
