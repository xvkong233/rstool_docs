# rsSlab · 参数楼板

> 模块：建筑 / 建筑构件

[← 返回命令目录](/commands/)

**功能**：由封闭平面曲线生成一个或多个向世界 -Z 方向加厚的封闭 Brep 参数楼板，并写入 RSTool 楼板类型及板厚元数据

**调用**：在 Rhino 命令行输入 `rsSlab`（命令行交互）

**交互流程**：

1. 在 Rhino 命令行输入 rsSlab
2. 在选择阶段按需点击命令行选项「板厚」，输入楼板厚度
3. 选择一条或多条封闭、共面的平面曲线；外轮廓与内轮廓可组成带洞楼板，互不相交的区域会分别生成楼板
4. 按 Enter 确认，命令沿世界 -Z 方向加厚并生成封闭 Brep 实体
5. 命令自动选中新楼板；后续可在对象属性的「自定义属性文本」中修改 RSToolSlabThickness，插件会按新厚度重建楼板

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 板厚 | Thickness | double | 0.2 m；之后沿用上次输入值 | ≥ max（文档绝对公差，0.001 m） | 选择曲线时可通过命令行选项修改；界面按当前 Rhino 文档单位显示，生成方向固定为世界 -Z |
| 参数楼板板厚 | RSToolSlabThickness | user text | 创建时的板厚 | ≥ max（文档绝对公差，0.001 m） | 生成后在对象属性的「自定义属性文本」中编辑，数值使用当前文档单位；输入无效值或重建失败时自动恢复原值 |

**备注**：rsSlab 生成带板厚元数据的封闭 Brep 楼板，创建和板厚修改均支持 Rhino Undo。

## 曲线要求

仅接受封闭且平面的曲线。用于同一楼板的外轮廓和洞口轮廓必须共面，并具有有效的嵌套关系；无法生成有效平面的曲线组合会被拒绝。选择多个互不相交的封闭区域时，命令会分别生成多个楼板。

## 参数化板厚

楼板顶面保留在输入曲线所在平面，实体沿世界 `-Z` 方向生成，因此倾斜曲线平面不会改变加厚方向。生成后选择楼板，在 Rhino 对象属性的「自定义属性文本」中修改 `RSToolSlabThickness`，插件会保留顶面位置并沿原加厚方向重建实体。该数值使用当前文档单位；必须为有效正数，且不能小于文档绝对公差与 1 mm 换算值中的较大者。

参数化依赖命令写入的楼板标记、面索引和几何签名。若使用其他建模命令改变楼板拓扑，插件检测到几何已不再匹配时会移除参数化标记，此后修改 `RSToolSlabThickness` 不再自动重建。复制或重新打开仍保持有效元数据的楼板，可继续修改板厚。
