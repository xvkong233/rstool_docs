# rsPaintBucket · 油漆桶

> 模块：组织与选择 / 材质辅助

[← 返回命令目录](/commands/)

**功能**：将吸取到的现有材质连续赋给点击的目标对象；支持普通物体和嵌套图块内部构件，图块中的修改会同步到共享该定义的所有实例。

**调用**：在 Rhino 命令行输入 `rsPaintBucket`（命令行交互）

**交互流程**：

1. 在 Rhino 命令行输入 rsPaintBucket，进入吸取材质状态，无需提前选中物体。
2. 直接点击一个已经分配材质的物体。吸取成功后，命令行会显示材质名称，并自动切换到涂刷状态。
3. 连续点击需要赋予同一材质的物体，每点击一次就涂刷一次。可以直接点击图块里的构件，不需要先炸开图块。
4. 需要换一种材质时，在命令行选择“重新吸取 / Repick”，再点击新的材质来源，继续涂刷。
5. 按 Enter 或 Esc 结束。已经完成的涂刷会保留；需要恢复时使用 Rhino 的撤销。

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 重新吸取 | Repick | 命令行选项 | 吸取成功后显示 | 点击选项 | 从涂刷状态返回吸取状态，换一个物体作为材质来源，然后继续涂刷。 |

**备注**：

## 像油漆桶一样连续赋材质

先点一个材质来源，再点需要换材质的物体就行，不用反复打开材质面板。吸取与涂刷时，视口光标会切换到对应图标，命令行也会显示当前状态和材质名称。支持曲面、多重曲面、挤出体、网格、SubD 和图块；需要直接点击，不支持框选。

吸取会读取点击位置实际使用的材质，包括按图层、按对象、从父图块继承的材质，以及可识别的面材质。默认材质或没有分配材质的位置无法作为来源，命令会提示重新吸取。

## 普通物体与图块的涂刷范围

普通物体按整个对象赋材质，不是只给点中的一个面上色。目标会改为“按对象”使用吸取的材质；多重曲面原有的单面材质覆盖也会清除，让整体使用同一种材质。

点击图块时，命令会穿透嵌套层级，找到点击位置对应的内部构件，直接修改它所在的块定义。因此，共享这份定义的所有实例都会同步换材质，包括嵌套在其他图块中的实例。想只改某一个实例时，先将它处理成独立块定义，再使用油漆桶。

## 贴图、退出与撤销

命令复制的是材质分配，不会把来源物体的贴图轴、贴图尺寸一起复制过去。贴图仍按目标物体原有的映射显示；若比例或方向不合适，需另外调整目标的贴图映射。

按 Enter 或 Esc 都是结束本次连续涂刷，不会自动恢复已经改过的材质。本次命令中的涂刷可以通过 Rhino 撤销统一恢复。

锁定或只读对象、锁定图层中的对象，以及链接或引用图块无法涂刷。点击后没有成功时，可根据命令行提示检查对象状态或重新吸取材质。
