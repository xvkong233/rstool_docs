# rsHelp · 打开帮助文档

> 模块：辅助工具 / 系统工具

[← 返回命令目录](/commands/)

**功能**：在默认浏览器中打开 RSTool 在线说明文档。

**调用**：在 Rhino 命令行输入 `rsHelp`（命令行交互）

**交互流程**：

1. 运行 rsHelp，系统默认浏览器会打开 https://docs.rstoolarchi.com/ 。
2. 通过目录或搜索查找命令说明。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：无需选择对象，也没有数值参数或设置窗口。需要能访问文档网站的网络连接。
