> 模块：视图出图 / 标注出图

[← 返回命令目录](/commands/)

**功能**：每个选中的 Layout 生成一个按布局名称命名的 AutoCAD 2018 格式 DWG。整张图纸压平到 DWG 模型空间的 Z=0 平面，按纸面毫米排布，而不是导出原始三维模型或保留 CAD 布局视口。

**调用**：在 Rhino 命令行输入 `rsExportLayoutToDwg`（打开设置窗口）

**交互流程**：

1. 先在 Rhino 中准备好 Layout：调整纸张尺寸、Detail 视图的投影与比例、图层可见性，以及纸面上的文字、尺寸和图框。命令没有可用布局时会直接提示并结束。
2. 输入 rsExportLayoutToDwg，打开“布局导出 DWG”窗口。也可从 RSTool → 视图出图 → 标注出图 → 布局导出 DWG，或 rsMenu → 出图 → 布局导出 DWG 打开。
3. 勾选需要导出的布局，可用“全选”“清空”“当前布局”快速选择。启动时若正在查看某个 Layout，默认只选中它；若在模型视图，默认全选。至少选择一页才能导出。
4. 通过“浏览…”选择导出目录，或填写完整的绝对路径。矢量精度默认 1200 DPI；一般先保持默认。只有确实需要替换旧图纸时，再勾选“覆盖已有同名 DWG”。
5. 点击“导出 DWG”，每页会分别处理。Rhino 命令行显示成功路径、失败原因和最终汇总；单页失败后继续下一页。按 Esc 可在当前处理步骤结束后停止，已完成的 DWG 会保留。

**备注**：

## 导出的尺寸与模型尺寸有什么区别

可以把它理解为“把整张 Layout 变成可编辑的二维 CAD 图”。多个 Detail 的投影、裁切范围和排版位置一起进入同一个 DWG，纸面上的文字、填充和图框也参与导出。它不会把 Rhino Layout 和 Detail 原样复制为 AutoCAD 的布局与视口。

输出统一按纸面毫米组织。例如 A4 横向图纸按 297×210 mm 的纸面范围排布；模型中 10 m 长的物体在 1:100 的 Detail 中，对应导出图上的长度约为 100 mm，并非仍按模型实长导出。纸张四周的空白不会自动生成边框，需要图框时请先在 Layout 中画好。

## 哪些内容能保留

命令通过 Rhino 原生矢量打印捕获布局，再由原生 PDF 导入和 DWG 写入生成文件，不需要安装 AutoCAD、VisualARQ 或虚拟打印机。会保留可矢量打印的投影、视图比例、Detail 边界裁切、剖切效果和可见性结果，并使用打印线宽；不是截图，也不是对所有三维对象重新做隐藏线计算。

文字尽可能保留为可编辑文字，曲线保留为 CAD 曲线，填充转换为填充对象。尺寸按打印外观拆分，不保留关联尺寸关系。字体、线型和图层会经过打印管线转换，因此不能保证原始文字语义、标注对象类型或 Rhino 原图层结构完全一致。

## 图片、着色和空白页的限制

采用 Layout 纸张范围和各 Detail 当前显示模式，只处理可矢量打印的内容。不会自动把着色或渲染视图转换为完整隐藏线图；图片、贴图和栅格着色也不能完整转换为二维线稿。检测到页面包含栅格图片时，该页会明确报错，而不是悄悄漏掉图片继续输出。

遇到此类提示，请移除布局中的图片、检查 Detail 显示模式，改成可矢量打印的表达后重试。没有可导出二维内容的空白页同样会报告失败，但不影响后续页面继续导出。

## 重名、覆盖和中途停止

文件名取自布局名称，Windows 不允许的字符会自动替换。名称处理后相同的布局会自动区分；目标目录已有同名文件时，默认继续加 (2)、(3) 等编号。覆盖选项请谨慎开启，它会允许替换旧图纸。

每页先写入临时 DWG，并回读确认有内容后再发布正式文件；单页生成或验证失败不会破坏已有目标文件。按 Esc 是在当前处理步骤结束后停止，并非立即中断所有计算。已经完成的文件保留，不会随取消一起删除。原 Rhino 模型不因导出而被压平或替换。

## 宏与脚本调用

使用带连字符的 -rsExportLayoutToDwg，可跳过窗口。第一个输入为 All 或 Current，第二个输入为绝对路径导出目录；直接回车使用 All。Current 要求先激活某个 Layout，处于模型视图时会提示并结束。

```text
_-rsExportLayoutToDwg _All "D:/Drawings/DWG"
```

仅导出当前布局时，将 All 改成 Current。脚本模式使用默认 1200 DPI，已有文件自动编号，不覆盖；需要调整精度或覆盖选项时，请使用交互窗口。
