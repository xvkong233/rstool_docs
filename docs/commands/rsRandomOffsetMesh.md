# rsRandomOffsetMesh · 随机偏移网格

> 模块：几何 / 网格

[← 返回命令目录](/commands/)

**功能**：新增逐面随机偏移的网格（Mesh），原网格保留；生成结果会成组并选中。

**调用**：在 Rhino 命令行输入 `rsRandomOffsetMesh`（打开设置窗口）

**交互流程**：

1. 在 Rhino 命令行输入 rsRandomOffsetMesh，打开随机偏移网格窗口
2. 点击“选取物体”，选择一个或多个网格，按回车确认
3. 设置厚度范围、偏移方向、是否生成实体，以及 UnweldMesh
4. 查看视口中的半透明预览，满意后点击“生成”

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 最小厚度 | Minimum | 数值 | 0.1 米（按文档单位换算） | ≥ 0，且不大于最大厚度 | 每个网格面单独抽取随机厚度的下限。 |
| 最大厚度 | Maximum | 数值 | 1 米（按文档单位换算） | ≥ 最小厚度；生成实体时须大于模型容差 | 每个网格面单独抽取随机厚度的上限；调整参数时随机分布保持稳定。 |
| 偏移方向 | Direction | 选项 | 法线正面 | 法线正面 / 法线反面 / 两侧（居中） | 沿每个面的法线偏移；居中时厚度分布在原网格面的两侧。 |
| 生成实体 | Solid | 开关 | 是 | 是 / 否 | 开启时为每个面做上下盖和侧壁，形成逐面厚度的封闭网格；关闭时仅输出偏移面，居中方向输出正反两层面。 |
| UnweldMesh | UnweldMesh | 开关 | 是 | 是 / 否 | 默认拆开面之间的焊接，让各面边界保持硬边。 |

**备注**：与 rsRandomOffsetSrf 不同，此命令是每个网格面各自随机取厚度，并非整张网格连续等厚偏移；想要分块、起伏的面板效果时可使用。
