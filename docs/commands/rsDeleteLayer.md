# <span class="rstool-command-icon rstool-command-icon--heading rstool-command-icon--single" title="rsDeleteLayer：工具栏图标" aria-hidden="true"><img class="rstool-command-icon__light" src="/command-icons/light/f39a492a-c491-5b08-a48e-5b4a4f5cc5fd.png" alt="" width="48" height="48" loading="eager" decoding="async"></span> rsDeleteLayer · 删除图层

> 模块：组织与选择 / 图层

[← 返回命令目录](/commands/)

**功能**：删除选定的图层

**调用**：在 Rhino 命令行输入 `rsDeleteLayer`（打开设置窗口）

**交互流程**：

1. 命令行输入 rsDeleteLayer
2. 在弹出的图层选择对话框中勾选要删除的图层
3. 确认删除

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：删除前会处理图层层级关系，请留意子图层是否一并被删除。
