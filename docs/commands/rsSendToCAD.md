# rsSendToCAD · 发送模型到AutoCAD

> 模块：辅助工具 / 导入导出

[← 返回命令目录](/commands/)

**功能**：将所选 Rhino 对象转换为 DWG 2018 数据并发送至 AutoCAD；在线时自动导入，离线时排队等待目标图纸领取。

**调用**：在 Rhino 命令行输入 `rsSendToCAD`（命令行交互）

**交互流程**：

1. 在 Rhino 和目标 AutoCAD 图纸中设置正确的真实单位，并打开准备接收模型的 AutoCAD 文档
2. 在 Rhino 中预选要发送的对象，然后运行 rsSendToCAD；如果没有预选，按命令行提示选择对象
3. 首次运行时，命令会为当前 Windows 用户自动安装或更新 AutoCAD 接收插件
4. 命令将所选对象以 DWG 2018 数据写入传输队列，并保持世界坐标、完整图层路径和 RGB 颜色
5. AutoCAD 接收端在线时会自动导入目标图纸并选中新对象；未连接时，批次保留在队列中
6. 如果批次没有自动接收，在目标 AutoCAD 图纸中运行 rsCadReceivePending；发送结果和传输编号会显示在命令行

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：

## 首次安装与接收

- 支持 AutoCAD 2020–2027。首次执行 `rsSendToCAD` 时，会从 RSTool 发布目录自动安装或更新当前用户的 `RSTool.CadTransfer.bundle`，无需管理员权限。
- 如果 AutoCAD 已经打开，新安装的插件通常需要重启 AutoCAD 才能加载；本次批次仍会保留。若 Rhino 提示旧版插件正在使用、更新已延后，请关闭 AutoCAD，再在 Rhino 运行一次 `rsSendToCAD`，随后重新打开 AutoCAD。
- Rhino 提示“接收端尚未连接”并不表示发送失败。启动或重启 AutoCAD，在目标图纸运行 `rsCadReceivePending` 即可领取排队批次。若该命令显示未知命令，说明接收插件尚未加载。

## 单位与转换规则

- Rhino 文档必须设置有效的模型单位；AutoCAD 图纸应设置正确的 `INSUNITS`。传输按两端真实单位换算，单位未定义或不受支持时命令会停止。
- Rhino 端使用 DWG 2018 导出：不展平模型，曲面和实体按 Solid 模式转换，网格保持为 Mesh，并保留完整图层路径、RGB 颜色及世界坐标。
- 文字、标注、填充和特殊对象的类型或外观可能因 DWG 转换而变化；动态块参数、外部参照及自定义对象数据不能保证保留。关键模型发送后应检查位置、实体封闭性、字体和标注。

## 选择与故障排查

- 有预选对象时直接发送；没有预选时才进入选择步骤。命令结束后会恢复运行前的 Rhino 选择状态。
- 无法由 Rhino DWG 导出器转换的对象会导致发送失败，具体原因显示在命令行。传输数据位于 `%LOCALAPPDATA%\RSTool\RhinoCadTransfer`，保留约 24 小时用于排查。
