# rsHotboxSettings · 热盒设置

> 模块：辅助工具 / 系统工具

[← 返回命令目录](/commands/)

**功能**：打开热盒设置窗口（含通用/布局与命令两个分页）；通用页编辑方案、主环 8 方向槽位、子环命令池分配；布局与命令页编辑后台监听、触发方式、按键、阈值与外观主题

**调用**：在 Rhino 命令行输入 `rsHotboxSettings`（打开设置窗口）

**交互流程**：

1. 命令行输入 rsHotboxSettings 打开设置窗口
2. 在「通用」页选择触发方式（轻点修饰键 / 短按长按 / 组合键 / 立即呼出），点击「录入按键」按下目标键或组合键
3. 调整长按阈值与轻点上限，选择外观主题
4. 在「布局与命令」页新增、复制、重命名或删除方案
5. 选择方向与层级编辑槽位，类型可选命令、宏或子环
6. 在命令库中按名称搜索、按分类筛选或按最近使用排序，双击命令分配到当前槽位
7. 点击「应用」保存并实时生效

**参数**：

| 中文名 | 英文名 | 类型 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 触发方式 | ActivationMode | list | 轻点修饰键 | 轻点修饰键 / 短按原功能长按呼出 / 组合键按住呼出 / 按键立即呼出并覆盖 | 热盒的呼出方式 |
| 长按阈值 | HoldMilliseconds | integer | 180 | 120-600 | 短按/长按模式判定为长按的毫秒数 |
| 轻点上限 | TapMilliseconds | integer | 250 | 120-500 | 轻点修饰键模式判定为轻点的毫秒数 |
| 外观主题 | ThemeMode | list | 跟随 Rhino 主题 | 跟随 Rhino 主题 / 始终深色 / 始终浅色 | 热盒面板配色 |

**备注**：热盒的两大自定义场景都通过本命令入口：(1) 改哪些命令出现在哪些方向槽位上；(2) 改热盒什么时候弹出、长什么样子。

窗口顶层有两个分页：「通用」与「布局与命令」，顶栏还有「← 返回上一层」按钮、底部则统一 导入 / 导出 / 恢复默认 / 应用 / 关闭 五个按钮。改动完一定要点「应用」才能在 Rhino 中立刻生效（不需要重启 Rhino）；点「恢复默认」会把所有方案与全局监听复位到出厂状态，导出按钮可以把当前完整配置保存为 json 文件方便备份/分享/团队统一，导入同理。

「通用」页布局：

① 左栏 方案 列表：每个方案是一套独立的 8 方向 + 子环布局，支持新增 / 复制 / 改名 / 删除 / ↑↓ 排序；典型用法是把不同工作流拆成多个方案（如「建模」「出图」「录屏」），按滚轮或中心按钮切换。多方案可绑定不同触发方式 + 不同快捷键，但建议一套配置起步用熟再扩。

② 中栏 主环层：固定 8 个方向槽位 N/NE/E/SE/S/SW/W/NW，编号 1-8 对应数字键；上方有「添加槽位」「删除选中」按钮，实际等于在某一层增加或移除子环方向槽位，最大 32 个；下方有类型/显示名/英文命令三栏，决定该槽位的动作形式：
- 类型 = 命令：直接执行某条 RSTool 或 Rhino 命令（如 rsWall）
- 类型 = 宏：执行一段 Rhino 宏（图中下方 Rhino 宏 编辑框）
- 类型 = 子环：在该方向上再展开 8 个二级方向槽位，子环可再嵌套一层（二级 + 三级，主环是固定结构不算），适合做 8 项分类快捷调用。

③ 中栏下方 子环列表：当前选中的子环槽位里已经分配的命令清单，可逐条编辑/修改/移除。

④ 右栏 命令库（RSTool 常用 + Rhino 常用）：内置覆盖 RSTool 全命令（约 280+）与 Rhino 内置命令池。上方 搜索 框 + 全部分类 + 按名排序 + 按拼音排序 + 按最近使用 四种过滤组合，可以快速定位命令；双击某条命令即分配到当前选中槽位，「加入当前子项」/「分配到当前槽位」按钮做相同事情的按钮形式。命令库底部「按最近使用」会记录你每次启动过哪些命令，方便找回平时用得多的。

⑤ 底部 勾选项：「执行前取消当前 Rhino 命令」—— 启用后热盒触发时会先发一次 Esc 把当前 Rhino 命令（如 _Line / _Offset）取消，避免出现'在 _Line 中再开热盒就卡死'的局面；一般建议勾上。

「布局与命令」页：

① 启用后台快捷键监听：主开关。开启后 Rhino 后台会以低优先级监听指定按键，所有 Rhino 视口都受影响，但只在 Rhino 活动视口拥有焦点时弹热盒；其他软件（Eto / WebView / 命令行 / 其他 Windows 应用）抢到焦点时不会触发。

② 触发方式：四选一。
- 轻点修饰键（默认）：点按 Ctrl/Shift/Alt/Cmd 等修饰键后即弹，松开即消失。一般初学者最直观。
- 短按原功能长按呼出：原功能（如 Tap）短按不变，按住 180ms 才弹。适合想复用已有快捷键的场景。
- 组合键按住呼出：双键按住不放才弹。规避误触但灵活性降低。
- 按键立即呼出并覆盖：按下立即弹，覆盖该键的原有功能。激进但效率最高。

③ 当前按键：「录入按键」按钮按下后即捕获下一次按下的键（含组合键），保存为当前触发组合。建议只用修饰键（Ctrl/Shift/Alt）作为根键，避免与日常编辑键冲突。

④ 长按阈值 / 轻点上限：毫秒数，决定「多短算短按/多长算长按/多快算轻点」；长按阈值默认 180，轻点上限默认 250。阈值得太小容易把正常点击识别为热盒触发，太大又会让弹热盒有可感延迟，按个人手感调。

⑤ 外观主题：三选一——跟随 Rhino 主题（自动）/ 始终深色 / 始终浅色。「始终深色」适合录屏与深色建模界面，避免热盒忽亮忽暗抢眼。

⑥ 提示语：底部会高亮当前判定逻辑——例如「轻点 Ctrl 期间不要出现其他键盘或鼠标操作，就会自动取消判断」+「短按/长按模式会在短按时回放原始按键」。

高级：可把命令库的筛选习惯（最近使用记录）和当前激活方案导出为 .rstoolHotbox 配置文件，发给同事一起用；导入时如与目标人当前方案冲突会提示合并或覆盖。
