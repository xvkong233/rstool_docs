# rsSectionBoxToggle · 开关剖切框

> 模块：视图出图 / 标注出图

[← 返回命令目录](/commands/)

**功能**：不改变几何：仅切换 Section Box 剖切显示的启用/关闭状态，主控盒对象保留（仍可移动、旋转、缩放、复制与撤销）

**调用**：在 Rhino 命令行输入 `rsSectionBoxToggle`（命令行交互）

**交互流程**：

1. 命令行运行 rsSectionBoxToggle
2. 选择要临时关闭或恢复剖切的 Section Box（点选或框选主控盒，支持运行前预选，可多选）
3. 命令自动判断：选区内只要有仍启用的，本次统一关闭；选区全部已关闭时再运行则统一恢复
4. 主控盒颜色随状态切换（启用=橙色，关闭=灰色），剖切显示即时更新

**参数**：

> 此命令无命令行数值参数，相关设置在窗口中调整。

**备注**：必须先用 rsSectionBox 生成剖切框，再对其主控盒运行本命令；本命令不创建也不删除主控盒，只读写主控盒上的 RSTool.SectionBox 用户数据并同步六个隐藏裁剪平面。选区含启用项→统一关闭，命令行输出『已临时关闭 N 个 Section Box 的剖切显示；主控盒仍保留。』；选区全为关闭→统一恢复，输出『已恢复 N 个 Section Box 的剖切显示。』。关闭后主控盒变灰、剖切消失，再次运行即可恢复剖切，且保留你对主控盒做过的变换（位置/旋转/缩放）。
