# rsPipeSchedule · 智能管道清单

> 模块：建筑 / 建筑构件

[← 返回命令目录](/commands/)

**功能**：读取智能管道对象的规格与长度记录，按类型、规格和生成时单位汇总成 CSV 清单。

**调用**：在 Rhino 命令行输入 `rsPipeSchedule`（命令行交互）

**交互流程**：

1. 运行命令，选择 rsSmartPipe 生成的管段和管件，按 Enter 确认。
2. 选择 CSV 保存位置；工具读取有效记录并汇总导出。
3. 用表格软件打开文件，检查类型、外径×壁厚、数量、管段净长、管件中心线长和生成时单位。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：只统计带有受支持智能管道数据（RSTool.Pipe.Version=1）的对象，普通 Pipe 或手工画的管件不会自动识别。CSV 使用 UTF-8 BOM，方便表格软件识别中文。清单采用生成时记录值，不会重新量取修改后的几何；若生成后缩放或改形，请重新生成管道再统计。无需设置窗口。
