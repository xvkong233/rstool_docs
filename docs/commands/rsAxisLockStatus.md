# rsAxisLockStatus · 查看轴锁定状态

> 模块：效率工具 / 生产力

[← 返回命令目录](/commands/)

**功能**：在命令行打印方向键轴锁定的运行状态，帮助判断为什么按方向键没有锁轴。

**调用**：在 Rhino 命令行输入 `rsAxisLockStatus`（命令行交互）

**交互流程**：

1. 运行命令，在 Rhino 命令行查看启用状态、世界坐标基准及最近的取点检测信息。
2. 若功能未开启，运行 rsAxisLock；若没有有效的带基点取点，请进入相应取点步骤后重试。

**参数**：

> 此命令无需设置数值参数，按上方流程操作即可；没有独立设置窗口。

**备注**：这是只读诊断命令，不修改几何、不自动开关轴锁，也不需要设置窗口。
